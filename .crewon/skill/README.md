# Crewon Skill

Crewon-specific project skills live here. Crewon loads this directory as a repository-scoped skill
root.

- `crewon-migration`: rules for product renaming, CLI/TUI cleanup, `.codex` preservation, and
  model protocol compatibility.

The existing `.codex/skills` directory is reserved for Codex agent tooling and should not be
renamed, deleted, or treated as product branding during the Crewon migration.
