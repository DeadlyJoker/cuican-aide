# 短剧工作台页面预览

这是可点击的前端预览，包含项目列表、创作需求修订、概念图版本、模拟生成/查询/选用，以及服务设置位置。数据只保存在当前页面内存，不连接模型、ComfyUI、生产 API，也不改变现有聊天与团队入口。

使用规则为所有用户可用，生成消耗个人独立积分；预览只说明该规则，不展示虚构余额、单价或实际扣分。

```bash
node artifacts/short-drama-workbench-preview/preview-server.mjs
```

使用仓库已固定的 Node.js 24 与 pnpm 依赖，打开 <http://127.0.0.1:5719/>。预览默认显示《窗边的来信》项目概览；左侧“项目总览”进入列表，概念图进入详情，“生成新版本”可体验描述确认、提交、查询、选用。

`assets/crewon-krea2-reference.png` 是之前真实 Krea2 连通验证保存的图片原字节副本，仅作为布局示意。它不是这些演示项目的生成产物；模拟查询不会生成或下载新图片。

实际项目服务、数据迁移和工作台任务关联仍需按照[产品方案](../../docs/short-drama-workbench-product-plan.md)实施。本预览不代表这些后端能力已交付。
