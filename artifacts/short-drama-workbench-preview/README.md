# 短剧工作台页面预览

这是嵌在现有 CrewON 页面框架中的可点击模块预览，包含项目列表、创作需求修订、概念图版本、模拟生成/查询/选用，以及服务设置位置。复用真实首页与侧栏组件，只新增“AI 短剧”入口；模块只占主内容区，继承宿主主题和公共控件。原首页及任务、助理、智能体、日程、团队和知识库入口保留。

数据只保存在当前页面内存。宿主通过明确的空资源读取器和演示回调组合预览，不连接账号服务、模型、ComfyUI 或生产业务 API；这个可信组件插槽原型不代表完整插件加载或第三方代码隔离系统。范围依据[插件可变边界](../../docs/plugin-variability-boundary.md)。

使用规则为所有用户可用，生成消耗个人独立积分；预览只说明该规则，不展示虚构余额、单价或实际扣分。

```bash
node artifacts/short-drama-workbench-preview/preview-server.mjs
```

使用仓库已固定的 Node.js 24 与 pnpm 依赖，打开 <http://127.0.0.1:5719/>。预览默认显示原 CrewON 首页；点击侧栏“AI 短剧”进入项目列表，打开《窗边的来信》查看需求和概念图，点击“生成新版本”可体验描述确认、提交、查询、选用。点击原导航返回原页面，模块内存编辑在页面刷新前保留。

`assets/crewon-krea2-reference.png` 是之前真实 Krea2 连通验证保存的图片原字节副本，仅作为布局示意。它不是这些演示项目的生成产物；模拟查询不会生成或下载新图片。

项目、需求及描述修订已有内部服务和 SQLite/PostgreSQL 存储基础；项目公共服务、真实页面保存、生成关联和结果选用仍需按照[产品方案](../../docs/short-drama-workbench-product-plan.md)接线。本预览不代表实际项目闭环已经交付。
