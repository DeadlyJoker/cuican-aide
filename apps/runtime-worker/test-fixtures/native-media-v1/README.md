# Native media acceptance data

Tracked Comfy API graph bytes copied from the public short-drama example templates. These are data-only test inputs, not an installable business plugin. The metadata fixture adds them and a generated media-input profile to its immutable descriptor before real installation. Its Node/UI entrypoints intentionally throw if imported.

Native preparation tests exercise actual package verification, Main review identity, saved configuration, worker CLI preparation, graph/manifest drift rejection and model catalog capture without importing Node or calling a model/provider. They must not depend on a previously built `output/` directory. This fixture is never a production installation source.
