# 设置页内容规范

设置页服务于使用产品的人，不承担架构说明、开发进度汇报或测试报告的职责。

## 默认展示

- 优先展示可操作的设置和用户可理解的真实状态。
- 帮助文字回答“如何操作、何时生效、保存在哪里、失败后怎么办”。与操作无关的解释不占首屏。
- 不把内部 ID、策略快照、激活目录、宿主/Worker、版本装配或“未接入所以不能假设”等工程说明展示为设置项。
- 没有管理能力的入口不展示空壳。旧路由和协议可以保留，避免影响兼容性。
- 未知状态仍须保持未知，但不要为“不显示 0”写一段免责声明。错误说明应给出下一步，不泄露连接细节或密钥。

## 必須保留的用户信息

- 保存时机、未保存修改、影响后续还是当前任务。
- 草稿不会自动发送，发送前需要核对内容与执行设置。
- 输入限额、凭据安全保存、运行中任务阻止模型切换等真实限制。
- 自定义模型连接表单需要服务地址和 Responses 兼容要求；这些属于配置所需信息，不应与内部运行架构一起删掉。
- 预览网页不自动授权智能体控制，草稿不代表已发生外部操作。

## 内部说明的归属

插件权限、摘要、版本固定、安装/回滚和模型适配的设计见 [插件化分析](./plugin-extensibility.md)；内置模板契约见 [capability-packs](../packages/capability-packs/README.md)。这些要求仍由代码和测试保障，不靠设置页里的说明文字实现。
