# CrewON App 使用说明

适用范围：2026-09-14 本地集成版，分支 `codex/sdd-integration-20260914`。本文介绍日常任务、表格交付、浏览器示教、Skill 试跑及日程执行。已生成并安装本地 arm64 DMG，见 [安装包及验收记录](sdd/dmg-installation.md)；尚未合回主分支或公开发布。

## 1. 启动与准备

本机已安装到 `/Applications/CrewON.app`，可从“应用程序”打开。也可挂载上述 DMG，将 CrewON 拖入 Applications。当前包未经过 Apple 发布签名和公证；本机首次安装与再次启动已经通过。

请使用 **0.1.1** 安装包，已修复旧版“账号服务暂时不可用”的打包与请求通道问题。账号密码登录、云端资源加载和退出重启后的登录保持已在本机验证。安装版默认连接 `pim.aicuican.com`，无需在本机启动账号服务。企业微信登录仍需服务端完成配置。

从本次集成工作区启动开发版，需要 Node.js 24、pnpm 10：

```bash
cd /Users/cheneywang/project/wqc/cuican-aide-sdd-integration-20260914
pnpm install --frozen-lockfile
CREWON_UI_PORT=5186 pnpm ui:desktop
```

先正常退出其他 CrewON 开发实例，避免单实例机制把窗口交给旧版。上面选择独立前端端口，启动命令会准备本地运行服务和桌面宿主。开发版仍使用设备上的 CrewON 数据目录；切换代码目录不等于创建全新的用户数据。

进入 App 后，完成界面要求的账号登录。打开左下角账号菜单 → **设置 → AI 模型 → 添加模型**，按模型服务填写服务地址、访问密钥和模型名称，选择 **保存并测试连接**。服务地址需符合该服务的 Responses 接口要求。不要把密钥写进任务正文或 Skill。

本轮支持本地桌面运行。浏览器教学需要 CrewON 桌面端，网页版没有这个采集能力。普通任务、模型选择、工作空间选择沿用现有入口；模型服务不可用时，生成 Skill 和 AI 执行不能完成。

## 2. 开始一个任务

1. 点击 **新建任务**，选择工作空间；无项目材料时可用 **无工作空间**。
2. 选择日常工作、代码或创意设计场景，填写目标、材料、输出格式和核对标准。
3. 通过输入框的 **+** 添加可用资源，确认模型与执行主体，点击 **开始任务**。
4. 在右侧工作台打开 **当前任务**。**产出** 查看对话生成内容，**浏览活动** 查看访问记录，**文件交付** 管理保存的表格文件。

用于表格交付的 CSV、XLSX 和模板，请通过 **文件交付** 上传。输入框附件和工作台的通用 **文件** 浏览器不等于这份任务的交付目录。只有已经建立的任务对话才显示 **文件交付**。

## 3. 先完成一次表格交付

### 上传与生成

1. 进入任务 → 右侧 **当前任务 → 文件交付**。
2. 用 **添加数据 CSV / XLSX** 上传一份或多份数据，用 **添加 XLSX 模板** 上传普通 Excel 模板。
3. 展开 **按模板汇集数据**，勾选来源工作表，确认每份来源的 **表头行**。
4. 选择模板、**目标工作表**、**数据起始行**。例如第 1 行是表头，数据从第 2 行写入。
5. 点击 **同名表头匹配**，核对来源表头与目标列；名称不一致时手动修改映射或 **添加列映射**。
6. 如需过滤、异常清单和汇总，勾选 **筛选、异常与分组汇总**，填写对应规则。异常、来源、汇总工作表应已存在于模板中。
7. 填写交付文件名，点击 **生成并保存 XLSX**。

同名匹配参考第一份已选来源的表头和目标起始行的上一行。汇集会处理各来源表头后的完整数据，不是只处理预览中可见的行。

### 一份可以直接练习的材料

使用仓库自带的合成样例：[订单 A](sdd/F01-delivery/fixtures/orders-a.csv)、[订单 B](sdd/F01-delivery/fixtures/orders-b.csv)、[订单模板](sdd/F01-delivery/fixtures/orders-template.xlsx)。前两份作为数据，模板作为 XLSX 模板上传。

| 设置                     | 填写内容                                                        |
| ------------------------ | --------------------------------------------------------------- |
| 来源                     | 两份 CSV，表头行均为 1                                          |
| 目标                     | 明细，数据起始行 2                                              |
| 列映射                   | order_id → A；channel → B；currency → C；amount → D；status → E |
| 排除条件                 | 表头 status，等于 canceled                                      |
| 必填表头                 | amount                                                          |
| 异常 / 来源 / 汇总工作表 | 异常 / 来源 / 汇总                                              |
| 分组表头                 | channel,currency                                                |
| 求和表头                 | amount                                                          |

预期读取 7 条记录，排除 1 条取消订单，1 条缺金额进入异常，写入 5 条有效明细。汇总应为直营 CNY 180、直营 USD 10、渠道 CNY 150。币种分组核对，不把人民币和美元相加。

### 核对、修改和下载

在 **已保存交付** 中选择文件，切换工作表、翻页，并展开 **文件验证与来源** 核对读取、写入、排除和异常数量。界面显示“已验证”表示文件结构及处理结果经过校验，业务口径仍需你检查。

点击交付表格的单元格，可修改文本、数字、布尔值、公式或清空内容；填写新值后选择 **保存新版本**。原件与历史版本保留。发生版本冲突时，编辑内容会保留，点击 **载入最新版本并保留编辑** 后重新核对再保存。

通过 **历史版本** 回看旧结果，通过 **下载原文件** 下载当前选择的文件。下载的 XLSX 可在 Excel 等软件继续编辑；外部修改不会自动同步回 CrewON 的版本历史。

## 4. 用操作演示教会 AI

1. 在右侧工作台打开 **浏览器**，点击地址栏旁的 **浏览器菜单（⋮）→ 浏览器教学**。
2. 在教学窗口输入完整 `https://…` 或 `http://…` 地址，点击 **开始录制**。
3. 在窗口中的教学页面操作一次：导航、点击、填写普通输入、选择筛选条件、下载文件。
4. 点击 **暂停**，在 **步骤回看** 检查记录。可看 **定位画面**、**删去此步**，或填写说明后 **保存说明**。
5. 确认步骤完整后 **结束录制**，点击 **生成 Skill 草稿**；也可 **导出 JSON** 留存录制。

跨网站时录制会暂停，需要你确认当前网站后 **继续**。页面加载失败或中断时，已保存步骤可回看；先打开教学地址，再继续录制。导出、修改步骤前需暂停或结束。

这是对 CrewON 教学页面的操作采集，不是屏幕录像，也不会录制你在任意 Chrome 标签或其他桌面软件中的操作。密码、令牌、Cookie 不作为演示数据采集。登录、验证码或敏感输入由你处理；特殊控件显示“无法采集”时，先解决这一步再生成可重复执行的方法。

## 5. 把录制变成可以复用的 Skill

录制交接后进入 **我的示教 Skill**，后续也可从 **智能体** 页面中的示教 Skill 列表打开对应条目。

1. 点击 **让模型整理草稿**，等待模型完成；需要时用 **更新生成状态**。
2. 审阅 **候选方法预览**，点击 **采用候选草稿**。录制导入只是起点，模型候选仍需你确认。
3. 在 **审阅与修正草稿** 中检查用途、方法步骤、依赖工具、完成标准、已知异常、运行时授权与准备。
4. 将日期、查询范围等会变化的内容设为 **变量**。步骤应描述如何取得结果，避免把演示那一次的订单号、金额和答案写死。
5. 点击 **保存草稿**，再 **保存新版本**。之后的试跑、调用和日程绑定这个固定版本。

例如“每次按输入的开始日期筛选已支付订单，下载 CSV，用任务内的模板生成 XLSX，核对明细数量和分币种汇总”，比“把演示中的 200 元填进去”更适合复用。

### 选择材料与试跑

先打开准备执行的任务，在 **文件交付** 上传本次数据和模板，再回到 Skill 库，选择该任务作为 **执行任务**。文件与结果保存在执行任务中；不要把其他任务的文件标识复制过来。

选择 **固定版本**，填写一组新日期或新输入，确认 **工具操作审批** 后 **开始试跑**。需使用浏览器时，先结束教学录制，再按下节完成授权。执行后点击 **查看运行结果**，检查实际网页结果和保存的文件。

| 工具操作审批     | 行为                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| 请求批准（默认） | 需要审批的工具操作暂停等你确认；你不在线时可能停在等待审批                                        |
| 帮我批准         | CrewON 代为批准整个本次任务或每次日程任务的工具操作，包含文件交付；浏览器授权及其操作范围仍然有效 |

这两个选项针对整个任务，不是“只允许改表格”。试跑和日程分别选择，日程不会因为上次试跑选过而自动沿用。

### 核对与激活

在 Skill 的 **运行记录** 中，找到完成的真实试跑，逐条勾选完成标准，如实勾选 **使用了新日期**、**使用了新输入**、**核对了已知异常**，填写 **结果核对说明**，点击 **确认核对结果**。

至少一项新日期或新输入的真实试跑核对通过后，点击 **确认激活**。模拟执行不能用于激活。激活后可 **运行此版本** 或 **添加到日程**。

修改方法时，保存新版本并重新试跑、核对、激活。已保存日程不会自动升级到新版本。**禁用 Skill** 会阻止该 Skill 的新执行；**重新启用 Skill** 恢复后仍需满足任务、资源和浏览器授权条件。

## 6. 浏览器授权与接管

浏览器操作授权与工具审批是两件事。点击 **允许此任务使用浏览器** 才将教学页面交给指定任务。普通模式按任务审批设置执行；需要限定范围的 Skill 还必须配置允许的网站与动作。

在 **浏览器授权方式** 选择 **限定范围连续执行**。需要此模式的 Skill 不提供普通授权选项。填写 **允许的网站**，例如 `https://reports.example.com`，不附带路径或末尾斜杠；再 **添加操作**，逐项选择点击、填写、选择、下载文件或打开页面。

对控件动作，选择按钮、输入框、下拉框等 **控件类型**，填写与网页一致的 **控件名称**。填写或选择的内容可用固定值，也可选择 **任务参数**。导航使用 **页面地址模板**，例如 `https://reports.example.com/orders?date={startDate}`，参数名必须来自当前 Skill，地址须属于允许的网站。每次最多 8 个网站、32 项动作，确认后点击 **允许此任务使用浏览器**。

范围表单目前没有持久保存。重新打开配置或重启后，如需重新授权，要再次填写；已经授予的权限不会因为你关闭配置面板自动撤销。更换任务、Skill 版本或范围，应重新检查授权。

点击 **接管并撤销授权** 可收回浏览器。App 或本地运行服务重启、浏览器关闭，以及把同一教学浏览器交给其他任务后，原授权可能失效；再次执行前重新授权。当前只有一个教学浏览器，不适合多个浏览器日程同时占用。

## 7. 让 Skill 按日程重复执行

1. 先完成真实试跑、核对并激活固定版本，选好参数和交付任务，点击 **添加到日程**。
2. 在 **新建日程** 中确认名称、固定版本、参数和绑定对话。新日期可选择 **运行日期**、**上一完整周开始（周一）** 或 **上一完整周结束（周日）**，也可以保持固定值。
3. 选择 **每天**、**每周**、**固定间隔** 或 **执行一次**。固定间隔至少 5 分钟。界面会展示当前设备的日程时区，日期参数按此时区计算；目前表单没有独立时区编辑器。
4. 明确选择本条日程的 **工具操作审批**，点击 **创建并启用**。
5. 对使用浏览器的日程，在日程卡展开 **浏览器授权**，完成指定任务与版本的授权。重启后也从这里重新授权。
6. 到期后打开日程对应的对话查看执行结果；表格仍在该对话 **当前任务 → 文件交付**。列表的 **执行** 可手动触发一次，失败时先查看原因再决定是否重试。

第一次建议选 **执行一次**，用新日期验证产物确实保存到预期任务，再安排重复执行。电脑需要保持唤醒，CrewON、本地运行服务、网络和所需页面保持可用。本轮没有云端托管或睡眠期间执行能力。

当前日程页支持创建、查看和执行，**尚没有单条日程的暂停、编辑和删除入口**。禁用 Skill 会影响所有引用它的日程，不能替代单条日程管理。需要频繁改计划的场景，先用单次执行或手动运行。

## 8. 常见问题

| 现象                           | 处理方式                                                            |
| ------------------------------ | ------------------------------------------------------------------- |
| 找不到浏览器教学               | 确认是本次集成的桌面版；从工作台浏览器的 ⋮ 菜单进入                 |
| 生成 Skill 草稿不可点          | 暂停或结束录制，确保有步骤且主窗口已连接 Skill 导入服务             |
| 新版本按钮不可点               | 先保存草稿；有提交状态待确认时先刷新或重试原请求                    |
| 找不到模板或输入文件           | 打开实际执行任务的文件交付目录核对上传记录；文件按任务隔离          |
| 等待审批                       | 打开执行对话处理审批；“请求批准”日程不会无人值守跨过此步骤          |
| 浏览器未授权或范围不足         | 结束录制，确认任务/版本，检查允许网站与动作后明确重新授权           |
| 页面中的控件无法识别           | 核对网页是否变化，检查录制中的不支持步骤；修正方法并保存新版本试跑  |
| 提交后没有收到响应             | 用“重试原试跑 / 重试原调用”或刷新原记录确认状态，保留同一次请求身份 |
| 文件保存发生冲突               | 载入最新版本并保留编辑，核对后再保存，不覆盖旧版本                  |
| App 退出后定时任务没有按时运行 | 本地执行依赖设备在线；恢复后查看原日程与对话记录，再处理未完成任务  |

## 9. 支持范围与验收状态

表格当前支持普通 CSV / XLSX、普通 XLSX 模板、分页预览、下载、版本化单元格修改。单文件最多 10 MiB，每任务最多 20 个输入文件，每张表最多 100,000 行、256 列。宏、外部链接、透视表等未支持结构会明确报错；本轮未交付 Word/PPT 同等级的文件流水线。

每份录制最多 200 步、30 分钟（含暂停）、2 MiB；最多保存 20 份本地录制。单一顶层教学页面受支持，iframe、新窗口、富文本、Shadow DOM、文件选择等特殊操作不保证可采集或重放。

已有合成业务站点上的真实模型、真实浏览器与真实 XLSX 验证，包含日程触发及同请求恢复去重；[查看已生成的样例 XLSX](../artifacts/f05-real-schedule/second-period-orders.xlsx)。这些证据不等于所有网站通用、人工桌面全流程或企业登录验收通过。

本轮界面复核与检查结果见 [App 可用性复核](sdd/app-readiness-review.md)。本机 DMG 安装、0.1.1 覆盖安装、账号密码登录与重启保持，以及此前包内文件处理与服务重启已通过；企业微信登录、其他企业业务站点登录、人工桌面完整业务流程仍待验收，不能把当前集成版当作已发布稳定版。
