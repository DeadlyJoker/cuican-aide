# 插件原任务产出与保存协议

2026-10-07。接续[插件内的结果预览](./plugin-media-result-preview.md)。本增量打通宿主中的原任务产出发现与候选保存协议；Short29 页面仍只提供已保存结果的列表和预览，新包的保存按钮尚未交付。

## 插件范围与兼容

保存能力使用单独的可选声明 `crewon.project-media-result-actions@1`。原 `crewon.project-media-results@1` 继续只读；仅声明原协议的包不能调用新动作。新服务需要原 Native `mediaResults.purposes` 包含 `publish`，并同时符合精确安装包、贡献点、profile、当前身份和原项目权限。旧配置、旧包、候选记录格式、原 HTTP 路由和冻结 SDK 均保持兼容。

动作仍通过原插件挂载的 `services.invoke`、认证请求和原 Core 执行。Web 与桌面使用同一传输分支，保存不替换当前预览图片，也不创建图片 URL。本增量没有改动任何主题、CSS、组件布局、首页、左右侧栏、账户或设置。后续按钮必须放在短剧自身内容区，遵守[插件可变范围](./plugin-variability-boundary.md)。

| 动作                                                   | 输入                                   | 结果                                                        |
| ------------------------------------------------------ | -------------------------------------- | ----------------------------------------------------------- |
| `crewon.project-media-result-actions.v1.listOutputs`   | `projectId`、原 `runId`                | 原输入及版本、连续的实际输出位置，各位置的已保存候选或 null |
| `crewon.project-media-result-actions.v1.saveCandidate` | `projectId`、原 `runId`、`resultIndex` | `created` 或 `replayed`，以及原候选元数据                   |

查询只读取已被原流程观察并记录为成功的 operation，最多 16 个位置；每个位置检查读取权限，最后重新核对原 operation。任务尚未观察完成时返回未就绪，不推测图片数量，也不代替 Agent 的 `media_observe`。返回值不含供应商 URL、文件名、凭据或图片字节。

## 保存与事务

保存借用现有 publisher，读取原输出、验证 PNG、冻结加密原件，再保存原项目候选。项目、原 Run 和输出序号构成稳定位置，重复保存返回原件，不发起新的生成，也不自动采用为角色参考或分镜素材。

真正的 UI 调用由 Application 私有登记；复制、重放或代理伪造的调用上下文不能取得保存资格。当前安装选择与包身份在 SQLite/PostgreSQL 的同一个结果事务内核验，并在提交前再次检查。PostgreSQL 的事务检查使用当前连接，异步身份与策略回调不重新占用提交事务的连接池。

下载期间撤权、挂载退出或保存模块关闭时，不提交候选。若字节已冻结而候选事务未提交，后续按原位置恢复可复用已验证原件。事务成功后通过私有提交结果返回；之后发生的策略变化不把实际已提交的写入描述为失败。通信中断仍需按原位置查询或显式重试，不能据超时认定未保存。

## 验证与限制

证据目录：`output/extensions/checks/media-result-actions-20261007/`。相关后端测试覆盖实际 SQLite/PostgreSQL、真实安装 handler、原任务、加密图片、真正 UI 调用登记、位置重放、只读拒绝、下载和 INSERT 期间撤销、提交后撤权与恢复。UI 传输测试覆盖保存、查询与当前预览共存。Native 原 Short29 安装和只读挂载回归仍保留。

这是协议和宿主通路验收，不是新保存按钮、完整 Agent 自动化或外部 ComfyUI 的现场验收。测试供应商响应、部分包校验和 PDP 为具名夹具；本次没有访问用户外部 ComfyUI，没有更新冻结插件包或用户当前 App。Mac 锁屏、浏览器无可用标签，未进行桌面目视验收。
