# AI 短剧工作台：产品交互与接力

2026-10-06。产品设计；实现范围以[进度](./incremental-extension-progress.md)为准。完整执行契约见[双入口规格](./short-drama-orchestration-spec.md)。

参考 [shuohao-skills](https://github.com/eternityspring/shuohao-skills) 的结构化阶段成果与确定性检查，采用 CrewON 自己的共享项目和执行协议。

## 一个项目，两个入口

用户在原 Agent 对话说出想法，也能直接打开短剧插件手动制作。两个入口读写同一项目、成果版本、采用结果和执行计划，随时接力。插件只增加功能模块，原聊天、侧栏、用户栏、设置和工作空间保持原有行为与样式。

项目概览集中展示故事目标、制作范围、当前成果、待处理事项和计划进度。阶段页面使用相同结构：**上游来源 → 当前成果 → AI 辅助/手动编辑 → 可用工作流 → 候选比较与采用 → 下一步**。不把八个阶段变成必须依次填完的向导；已有剧本、角色或单镜头满足必要输入即可进入相应制作。

| 阶段         | 用户能看到和编辑的成果                    | AI 与工作流怎样配合                                     |
| ------------ | ----------------------------------------- | ------------------------------------------------------- |
| 需求与方案   | 故事目标、受众、风格、集数/时长、制作范围 | Agent 整理想法，需求检查器发现缺口，保存明确方案        |
| 大纲与分集   | 人物关系、主线、分集情节与悬念            | AI 编剧生成候选，结构/分集覆盖检查；可只重写一集        |
| 分集剧本     | 场次、动作、台词、情绪、对白清单          | AI 创作或局部改写，引用检查、对白提取与时长估算         |
| 角色与美术   | 角色、服装、场景、道具设定及参考图        | AI 美术完善设定，Krea2 等探索概念，选定参考后再派生     |
| 分镜         | 镜头表、构图、运镜、动作、对白与声音意图  | AI 拆镜头，检查剧本覆盖和素材引用，再转换供应商分段     |
| 关键帧与视频 | 每镜输入、候选图/视频、实际任务状态       | AI 准备描述，用户或授权规则确认；对应图像/视频 API 执行 |
| 配音与声音   | 角色音色、逐句配音、音乐/音效与对齐       | AI 声音设计，TTS/音乐工作流生成，按实际时长对齐         |
| 剪辑与交付   | 时间线、字幕、预览、成片与交付检查        | AI 提议节奏，确定性编排和外部合成使用确切采用素材       |

这张表是目标产品范围，不表示后五项已经交付。每个阶段的状态分别显示“内容已保存”“候选待采用”“制作进行中”“结果待检查”等事实，避免用一个“完成”掩盖缺失产物。

## 从一句想法开始

例：“做三集雨夜悬疑，先完成大纲和第一集剧本，给女主探索两张形象，暂时不做视频。”

Agent 在原对话提出一张可编辑制作卡：故事范围、执行到角色探索、所需步骤、两张图的数量、文本采用规则、图像由用户挑选。已明确要求执行的部分按范围推进；只有询问构思时先讨论，不启动制作。没有指定的关键条件，只补问影响下一步的缺口。

文字生成后保存候选，通过结构检查后按用户选择的规则采用。角色设定确定后保存画面描述，再调用实际可用的 Krea2 工作流。每个候选对应自己的原任务和输入版本，到指定终点停止。对话给简短进度与成果卡片，点击打开同一项目的具体成果。

用户可以中途进入工作台改一句台词并采用，或者挑选女主参考图并锁定。回到对话说“继续第一集分镜”，Agent 重新读取已采用来源，提出或执行分镜范围，后续工作流使用确切参考。锁定内容不被自动换掉。

## 手动制作也能使用 AI

阶段页提供三个清楚的动作：**自己编辑、让 AI 帮我处理、执行已确认输入**。

“让 AI 处理”可以只完善一项描述、重写选中场次、补单个镜头，也可以推进到指定终点；对话与页面都使用同一业务命令和计划记录。“执行”使用已经确认的文本、素材及参数，不在发送前悄悄改写。生成结果进入候选区；用户比较、采用、锁定，或明确再生成一个候选。

工作流按用途和输入匹配：T01/T04 用于文本形象探索，T10 需要一个已采用角色参考，D18 需要场景和两个有顺序的不同角色。D18 的图像探索不能替代完整镜头表。视频、声音与合成各用对应的已验证 API；未接通时展示缺失条件，不能提供实际无法执行的按钮。

## 自动化如何接力

计划保存起点、终点、业务项、确切来源、允许工作流、候选数量、并发上限、采用规则与停止条件。Agent 负责创作与建议，宿主按依赖执行和恢复；关闭页面不丢失服务端计划。

- 只保存上游草稿，不影响正在使用的正式版本；采用新版本才标出受影响的下游。
- 已提交的任务保留原来源，迟到结果不会覆盖用户后来采用的结果。
- 没有自动采用授权时，在相应取舍点等待用户；其他独立项可继续。
- 暂停阻止新的步骤，不宣称已经提交的外部作业被取消。
- 结果未知时查看并核验原任务；“再生成”是用户明确发起的新尝试。

同一 `crewon.short-drama` 安装包包含页面、阶段指导、检查器、Agent 工具与多个适配器。后续新增媒体能力按公开插件协议扩展包内目录，宿主负责共享项目与原 Run。积分按用户要求后置。
