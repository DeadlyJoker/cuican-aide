# 插件页面的有限租约续期

插件页面需要连续使用，并保留未保存的草稿。原挂载具有五分钟的绝对期限，页面每秒验证权限但不续期；到期后加载器和 Native 资源代理都会撤回，页面只能重新进入。

新增显式 `POST /api/v1/plugins/ui/mounts/:mountRef/renew`，请求只包含原 `expectedExpiresAt`，响应仍是原 `crewon.plugin-ui-lease.v1`。旧 GET 验证继续只读，不隐式延长权限；旧客户端无需变化。Native v1 桥增加可选 `renew(bindingRef)`，没有这个能力的旧桥保持原行为。

Control 只给仍然有效的同一挂载续期。原 actor、profile、授权 epoch、启用选择修订、包摘要、贡献入口和完整公开资源清单均重新检查，包字节重新验证；原期限必须在检查结束时仍有效且与请求完全一致。续期只更新私有 owner 的租约快照，同一个 owner 继续约束在途操作。关闭、过期、换包、撤权或并发旧期限不匹配均不能复活。每次租约最多五分钟，不提供无限有效的租约。

页面在原期限剩余一分钟时发起续期。宿主先等待已经开始的验证和动作实际结束，同时挡住新操作；一次续期由同一 owner 的并发调用共享。取消等待不会忘记实际执行中的工作，实际撤回会取消续期。续期响应只允许期限单调增加，其他规范化字段必须完全相同；资源与等待者数量保持有界。

Web 宿主沿原鉴权客户端调用新接口，保留原 CSRF、请求预算和响应字节限制。Native 由 Main 保存的原会话与 binding 发起请求，前后进行原 GET 校验，更新同一 binding 的期限及原撤回计时器。资源地址、完整文件摘要、session、Control 进程归属与原 frame/sender gate 保持。未知结果关闭模块，不以重挂或再次安装代替确认。

续期同步更新加载器与回执恢复的租约，不重新导入代码、不重新创建模块、不 hydrate 日志，不发送生成或供应商请求。原 DOM、草稿、焦点、选区及已受理请求保留。原阶段提交、回执观察、生成幂等键和五秒动作预算不变。退出模块、切换账号或 pin、过期与真正撤权继续关闭原实例。

验收分别覆盖协议与兼容性、实际 HTTP 和 BFF、同一 DOM 的五分钟后动作、原回执与取消链，以及真实隐藏 Electron 的原 preload/IPC/资源代理/测试 Control 链路。测试所用身份、包与时钟是具名边界，不代替实际安装的完整 App 或真实生图。实际安装与验证结果记录在[实施进度](./incremental-extension-progress.md)中。
