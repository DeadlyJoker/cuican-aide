2026-10-06。状态：同一短剧包页面、公开客户端及宿主分页已实现；真实用户 App 安装、Agent 输入命令与媒体制作联合验收继续实施。接续[页面输入服务](./project-media-input-ui-protocol.md)，产品交互见[双入口体验](./short-drama-product-experience.md)。

## 四个动作与同一原记录

`crewon.project-media-inputs@1` 在原 `loadInput/saveInput` 形状不变的基础上增加 `listInputs/getOptions`。新版包在同一 `workbench/main.content` 内使用独立、无 import 的 portable 客户端及严格 codec；构建固定摘要，不修改 SDK 源、dist 或 tar。

`listInputs` 从原 SQLite/PostgreSQL 输入 head 按稳定 UTF-8 顺序读取，每页1至16项，页面默认8项。游标只是最后一个输入 ID；额外一项决定是否有下一页。每项摘要只有原项目/输入身份、最新输入修订、业务项、工作流及时间；完整提示词和引用仍通过 `loadInput` 读取。Application、Store 与返回合同核原身份、顺序、重复及游标，查询不写项目或任务。

`getOptions` 沿原项目读取授权，返回当前确切短剧包配置的修订及 T10/D18 逻辑工作流标识；包、配置与审查版本不符时不提供可用配置。响应不包含服务地址、凭据、图或执行资格。目录提示不代替生成准入、素材准备或网络权限。所有四个动作仍使用真实活跃 invocation、原 issued request、同一 SQL owner 和页面 read/write 目的；安装声明和 UI 服务批准保持独立。

## 实际插件页面

原第四阶段增加“参考与分镜探索”，复用模块的表单、两列/窄屏布局及宿主主题变量。角色、场景和剧本选择器只展示当前需求下的已采用版本，分页加载更多明确来源。T10 需要一个角色参考，剧本可选；D18 需要剧本、场景及两个不同的有序角色。提示词必须满足8192 UTF-8字节及完整16KiB请求预算。

保存生成不可变输入修订。编辑历史修订会保留原需求、脚本和素材引用；仅修改提示词不会跟随刷新静默改用新来源。用户须明确点击“使用当前需求和已采用版本”更新来源，服务端仍核全部当前版本。列表重新打开确切历史；重新进入模块只读取已确认原记录，不创建 Run。

客户端发起保存前完成严格编码检查；无效 Unicode、请求预算、重复角色和不完整来源不建立未知请求。发送后的结果未知保留完整原输入和原键，明确重试同一请求；在途物理写入与其他模块写入互锁。已确定冲突允许处理草稿，未知权限/传输结果不自动换键。真正保存后刷新原 head；其他入口后来追加的修订不会被旧回执冒充为最新。

页面撤回就绪或卸载会取消本次读取与迟到投影，不把物理写调用视为已退出。当前实现支持本次挂载的未知请求重试和已确认输入的冷读取；未确认媒体保存的跨重启持久 journal 尚未接入，未发送草稿也不持久保存。
