# Web 插件代码缓存

刷新后重新校验当前账号和挂载，不应重新下载同一版本的插件整包。代码字节按站点、账号、发布者、插件、包摘要、入口路径与文件摘要分区；项目、会话、凭据、权限、服务对象及 UI 状态不进入缓存。

## 协议与兼容

- Web BFF 通过会话响应头 `x-crewon-plugin-ui-assets: entry-bytes.v1` 声明显式支持；原会话 JSON 字段保持不变。旧客户端忽略响应头，旧 BFF 和桌面沿用原加载方式。
- 独立插件声明可选服务 `crewon.plugin-ui-resources@1`，对应 SDK 可选只读对象 `services.resources`。它包含协议版本与当前挂载的入口地址，不含凭据，不赋予业务权限。缓存导入的插件用该地址解析内置图片等资源；旧宿主缺少此对象时仍可使用 `import.meta.url`。
- 只有单个公开入口的自包含 JavaScript 模块启用字节缓存；多资源或未声明的模块保持原生 URL 导入，避免改变相对依赖的执行上下文。
- 短剧 50.1.4 增加上述可选声明和资源定位兼容，沿用原产品界面及业务数据。已发布的 50.1.2、50.1.3 文件和摘要保持不变，新版本更新同一个插件选择，不重复安装另一个插件。

## 每次挂载的真实路径

宿主先取得、校验当前租约，再查询账号分区内的 IndexedDB 字节缓存。缓存只保留八个入口，单个不超过 4 MiB。使用前逐一验证文件长度和 SHA-256；损坏、缺失或不同包不会参与缓存确认。

即使字节已缓存，宿主仍向原挂载的资产地址请求，附上文件 ETag。BFF 首先通过原账号、Control 租约、主体、安装选择、文件发布与真实字节校验，然后才计算 ETag。只有成功的 JavaScript 读取可以响应 304，正文为零字节。关闭、撤权、账号切换或传输失败不能转为离线成功；不重试业务任务。旧的普通资产请求仍为 `no-store`，只有显式代码缓存请求返回 `private, no-cache`。

校验后的字节为每次挂载分别创建模块 URL，完成导入后释放 URL。不同项目不共用模块全局变量、实例、DOM 或服务。原导入前、实例创建前和发布前三次校验保留。资源定位使用该实例自己的原挂载地址，避免过期地址影响后续页面。

存储不可用或额度不足时，仍执行原在线授权及字节校验；它不会阻止合法挂载。代码缓存不使尚未配置的 Agent 执行服务变为可用。

## 连接恢复

Web 首次控制连接使用当前账号的一次 POST 会话交换。五秒的初次展示期限不丢弃随后返回的合法连接：原请求在十五秒传输期限内成功、账号代次仍一致时，页面采用原结果。退出或更换账号后的结果不能接回页面；业务任务的重试和幂等语义不变。

## 验证范围

回归通过真实安装、文件校验、Control 资产授权与 BFF，覆盖新租约 304、零正文、旧请求兼容、关闭、撤权及另一真实主体拒绝。入口导入器覆盖新的加载器复用持久字节、账号分区、损坏字节、取消和网络错误；原挂载生命周期与视觉覆盖仍适用。线上和浏览器验收另行记录，源码回归不代表公网体验已通过。
