# 插件 UI 代码复用

宿主侧栏与右侧工作台拥有独立的挂载租约。相同包的两个页面可以复用自包含的代码，但不能复用权限、服务、页面状态或实例。

可信 UI 模块可以通过具名 ESM 常量 `export const crewonUiResourceMode = "self-contained.v1"` 声明自包含资源。该声明要求 JavaScript、CSS 和内置资源全部包含在构建产物中；模块不得依赖首次挂载 URL、`import.meta.url`、相对动态导入或挂载目录下的图片地址。此约定不赋予业务权限。

缓存位于一个宿主加载器内，以插件、发布者、版本、包摘要、入口路径和文件摘要组成完整键。最多保留八份已校验的代码及八个下载任务；账号或宿主作用域切换后，新加载器不继承缓存。并发首次挂载可以等待同一个代码下载；只有模块明确声明自包含时才共用下载结果，否则第二个实例仍从自己的租约 URL 导入。失败不会保存为有效缓存，也不会自动重试请求。

每次挂载仍独立执行导入、实例创建和发布的三次实时校验，分别创建服务对象、实例和 DOM。撤权、租约关闭及取消等待仍拒绝发布和业务操作。代码复用不是权限缓存，也不是第三方代码沙箱。

旧插件没有此导出时保持原加载行为。短剧 50.1.4 首次启用该声明；50.1.2 和 50.1.3 的已发布包保持原摘要，不覆盖已有版本。

Web 首次控制连接使用当前账号的一次 POST 会话交换。页面五秒的初次展示期限不再丢弃随后返回的合法连接：原请求在十五秒传输期限内成功，且账号代次仍一致时，页面采用原结果。退出登录或更换账号后的结果不会接回页面。这不改变业务任务的重试和幂等语义。
