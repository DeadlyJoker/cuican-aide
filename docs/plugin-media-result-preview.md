# 短剧插件内的已保存结果预览

2026-10-07，独立短剧包 29.0.0。接续[桌面结果保存与读取](./native-project-media-results.md)。本增量在项目的“参考图与分镜探索”页增加已保存结果列表、输入版本、图片尺寸和预览。它读取原项目、原 Run 和原输出位置，不新建会话或重新生成图片。

## 主题与可变范围

遵守[插件可变范围](./plugin-variability-boundary.md)：复用插件已有表单、面板、按钮和宿主下发的主题变量。新增样式仅匹配 `.drama-workbench` 下的图片容器；宽度由内容插槽决定。预览直接显示在插件面板中，不创建全局弹层、侧栏、账户区或主题切换器。

每个挂载只持有一张预览图片。关闭预览、替换图片、离开页面、切换项目或卸载时释放本实例的图片 URL。旧请求晚到时不能写回新项目，旧预览的清理也不能撤销新预览。宿主在最终挂载校验失败时取消该调用，清理已经创建但没有交付的临时资源。

## 协议与权限

包通过冻结 SDK 的通用 `services.invoke` 使用可选服务 `crewon.project-media-results@1`，没有重建或修改 SDK。独立可移植客户端与严格编解码器单独固定摘要。

- `listCandidates`：原项目分页目录，每页最多 16 条；插件最多保留 64 条，刷新重新开始。
- `preview`：项目 ID、原 Run 和结果序号。服务器校验真正的 UI 调用、当前安装包、贡献点、身份、profile 和项目权限，并通过原结果读取器验证图片。服务器只返回候选元数据。
- `releasePreview`：只在渲染器处理，按当前挂载及精确 URL 释放资源，不产生 HTTP 或业务写入。

Web 与桌面共用图片传输逻辑：取得获准元数据后，经原认证 Control Client 读取冻结 PNG；校验长度、摘要、候选 ID 后再检查挂载，创建本地 Blob URL。插件不接收凭据、供应商地址、归档密钥或大体积 Base64。

Native 使用现有 `mediaResults` 声明中的精确包和 `workbench` 范围，并要求包声明该可选协议。读取采用原配置请求上下文，不访问生成 peer。没有声明、包摘要不符、挂载关闭或身份变化时拒绝读取。旧包、旧配置和原 HTTP 接口保持兼容；旧宿主允许安装可选声明，但读取不可用时插件显示可重试状态。
