# AI 短剧插件：本地内容与共享 Agent

## 目标与边界

复用 CrewON 的 Agent、会话、模型、权限、工具调度和恢复机制。插件提供短剧阶段提示、少量业务工具和项目页面，不创建第二套任务引擎或聊天目录。

采用 `ai-short-drama-production` 的制作协议：brief、script、bible、shots、assets、generation、qc、release。阶段是依赖提示，不是必须逐次审批的固定流水线；在已有授权内连续推进，返修只处理受影响的产物。生成完成、质量验收和用户采用分别记录。

## 数据归属

- 项目工作空间中的文件是内容的唯一权威来源。需求、剧本、设定、分镜、提示词、审阅意见以 Markdown/JSON 保存，媒体保留原始文件。
- 数据库保存任务运行状态、外部生成 ID、幂等提交信息、文件相对路径与摘要索引。索引可从文件重建，不再承担正文版本库。
- 每份文本内容保留不可变 revision 文件；读取最新版本从 revision 文件序列确定。无需跨 SQLite 与文件系统维护一个“当前正文”事务。
- 修改要求 expectedRevision；并发编辑返回冲突，不能覆盖另一方内容。相同内容的重试复用当前版本。写入中断留下的临时文件不算有效版本。
- 既有 SQL 正文保持只读迁移源。迁移须逐项目导出、核对摘要、切换存储模式；未切换项目继续使用旧入口。禁止静默双写或自动删除历史。

## 工具与交互

Agent 使用宿主现有工作空间授权。项目工具只需要列目录、限量读取、保存修订、打开页面与提交/查询生成；不为每种资产再建一套 CRUD 服务。文件路径由受信项目根目录和相对路径组合，不接受任意绝对路径。

阶段提示每次只注入当前阶段、必要约束、产物路径及版本，内容按需读取。不能把整项目正文塞入系统提示。用户材料属于数据，不提升为指令。

右侧项目页面提供概要、正文/资产、生成与审阅视图，直接读取相同文件。保存复用同一版本冲突逻辑。Agent 打开页面只导航到项目与文档，不代表生成、采用或发布。文件提交成功后通知页面刷新；刷新失败保留文件与未同步提示，不能回滚已保存内容。

会话继续使用工作空间目录；插件可以显示项目内会话过滤结果，但不得重新实现卡片式聊天系统。打开文档不切换当前会话或清空输入草稿。窄窗口页面以可收起面板呈现，保留主输入框的可读宽度。

## 开发顺序与验收

1. 本地不可变文本修订存储：真实文件读写、重启读取、幂等重试、并发冲突、路径隔离和中断文件处理。
2. 接入受信工作空间宿主，再贯通 Agent 工具与页面同读同写；没有授权的项目不能创建存储。
3. 逐项目迁移旧 SQL 内容，校验内容摘要；切换后 SQL 正文不可再写。
4. 对接既有页面导航/刷新，验证 Agent 保存后页面变化、页面修改后 Agent 读到新版本。
5. 保留外部生成提交幂等与未知结果恢复，验证断线只查询原任务，不重复扣费或生成。

本批仅实现第 1 项存储基础。尚不宣称完成工具/页面接入或旧项目迁移；现有生产读写路径保持原状，直到第 2、3 项验收完成。
