# ReelBench 两类项目复刻：可执行验收清单

2026-10-08。本文是待执行的验收规格，**没有任何用例已通过**。先完成两类项目的分析和 CrewON 适配决定，再依此实施与验收；不得先改页面，再把已有实现写成参考站的行为。

范围是完整复刻 ReelBench 的功能、使用逻辑、页面组织、交互和产物关系。视觉使用 CrewON 原有主题，Agent 对话复用主页现有对话框和能力，插件遵守宿主边界。依据为[完整产品拆解](./reelbench-product-replication-analysis.md)；[页面参考记录](./short-drama-reelbench-ui-reference.md)、[现有产品规格](./short-drama-product-experience.md)和[执行规格](./short-drama-orchestration-spec.md)保留为历史观察或 CrewON 设计，不能替代本次核查事实。

## 证据和通过标准

本清单的参考输入来自登录后页面的只读观察：导航、阅读、打开和关闭弹窗。**没有在参考站提交生成、保存、历史恢复或批次撤销。** 下文的“参考事实”只证明控件、字段、文案、已有状态及层级可见，不证明其执行成功、持久化语义或内部实现。

| 标记 | 含义                           | 用法                                                                |
| ---- | ------------------------------ | ------------------------------------------------------------------- |
| R    | 参考站只读可见事实             | 记录页面路径、项目类型、状态、控件和说明；动作结果仍需验证          |
| A    | CrewON 适配要求                | 来自用户约束或已经明确的宿主/插件规则；不能描述为参考站原实现       |
| R+A  | 参考交互与 CrewON 适配共同约束 | 保持对应业务交互，执行落在 CrewON 同一项目、版本和原 Agent 运行路径 |

每个用例必须留下：执行版本和插件包身份、隔离项目和对象身份、操作前状态、实际操作、操作后页面、再次读取的持久记录、关联执行/供应商任务和失败信息。对象身份和任务号用于验收证据，不要求在产品页面展示。

只有以下证据同时成立，写操作或生成用例才能通过：

1. 用户通过正式界面完成动作，范围和结果表达清楚。
2. 实际业务服务接受动作，并可重新读取对应持久成果；页面重新打开后仍一致。
3. 涉及生成时，真实外部服务产生可读取、可预览的结果，项目对象和输入版本正确关联。
4. 失败、未知回执、重复点击和重启不会伪造成功或重复提交任务。

快照、组件测试、模拟服务、模型口头声称完成、HTTP 200、任务受理回执均不能独立证明整条业务用例通过。只读页面用例可以先验收；涉及尚未接通的服务，记录“未执行”或“阻塞”，不能把删除按钮、显示静态图或测试夹具当成完整复刻。

验收记录统一使用：**未执行 / 执行中 / 通过 / 失败 / 阻塞**。不得将“已看到控件”记成“通过生成/恢复/保存”。

## 前置准备

- 使用专用验收项目，保留用户原项目和历史任务；不为测试恢复而重新提交原来回执未知的生成。
- 准备 C0 空创意项目、C1 含剧本/角色/美术/分镜文本但没有图片的创意项目、N0 小型小说项目、N1 已有资产图与分镜的小说项目、N2 大型小说项目。内容用新建测试资料，不复制参考站用户小说或创意正文。
- N2 至少覆盖 120 集、389 章规模以及多批生成。参考站可见实例是角色 1/1、美术 4/4、剧本 9/40 步、每步 3 集的中断状态；测试资料须能构造同类中断，而非假设这些数字是所有项目的固定限制。
- 准备 TXT、MD、HTML 的合法、空白、编码异常、超过上限文件，以及恰好达到产品声明上限和多 1 字节的文件。参考界面声明上限为 20MB；必须先明确字节口径，再验收边界，不能默认将 MB 当作 MiB。
- 准备真实可用的文本模型、Krea2 生图和实际拟接入的参考图/视频服务；记录能力、输入要求及失败处理。未知或未配置的能力不得提供会误报成功的执行入口。
- 准备可控制的断网、关闭页面、冷启动、外部提交响应丢失、确定失败条件。测试扰动只作用于隔离验收环境。
- 在分析文档中分别固定两类项目的页面树、数据对象、依赖、主要操作和状态迁移。尚未明确的语义列为阻塞项，不能临时用当前代码行为代替。

## 阻塞项和最终交付门槛
