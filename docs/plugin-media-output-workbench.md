# 短剧插件内的原任务产出保存

2026-10-07，独立短剧包 30.0.0。接续[原任务产出与保存协议](./plugin-media-result-actions.md)，在现有“参考图与分镜探索”页接入产出查询、逐张保存、恢复和预览。

## 页面与主题边界

本次没有增加 CSS，沿用插件现有的面板、按钮、提示和版本标签。主题继续由宿主下发，变量只写入插件自己的根节点；不改 CrewON 的首页、左右侧栏、工作空间、账户或设置。保存中切换主题保留当前请求和输入，插件以宿主分配的内容区宽度布局。

产出面板直接放在原输入面板和已保存结果之间，不创建全局弹窗。该约束与[插件可变范围](./plugin-variability-boundary.md)一致。

## 操作与恢复

1. 取得当前项目的原生成回执后，按其中的原 Run 查询已记录的产出。没有同项目回执时不展示面板；任务尚未记录成功产出时显示可刷新提示。
2. 每个已发现的输出位置提供“保存结果”。提交仅包含原项目、原 Run 和输出序号，不能指定外部 URL、图片字节或其他位置。
3. 保存成功后立即提供预览，无需等待该候选出现在分页目录中。候选仍经原宿主图片读取与校验，不在插件里直接访问供应商。
4. 停止等待或回执丢失后，先刷新原位置。如果已保存，使用原候选；暂未找到时才允许用户显式重试原位置。刷新不会自动写入或再次生成。
5. 写入尚未返回时保留物理请求锁；切换项目、停用或卸载后，旧响应不能写回新项目。重新挂载时从原生成回执重新查询，不依赖插件内存宣称保存成功。

“保存”只是保存项目候选，不等于采用为角色参考、场景或分镜素材。采用仍需原素材版本协议和冲突检查。

## 独立包与兼容性

包通过冻结 SDK 的通用调用接口声明可选服务 `crewon.project-media-result-actions@1`；原 `crewon.project-media-results@1` 仍负责只读列表和预览。没有重建 SDK，也没有改写旧包。缺少新服务的宿主仍能安装该可选声明；产出查询不可用时保留原页面并显示刷新提示。
