## 旧插件兼容更正

后续真实Web/BFF/Control/Worker/PG全App回归发现：冻结Professional 2.0.0使用宿主tasks投影，必须先由用户明确创建原Thread，其UI只提供`report.generate`，没有自己的创建/打开会话动作。移除所有通用操作后，首次使用无法获得Thread，属于兼容回归。

当前源码仅为这类旧模块保留必要的创建、同键恢复和打开原任务按钮：必须已真实挂载、具有task端口和tasks服务声明；声明项目会话、会话关联或生成上下文任一协议的现代模块不显示它。AI短剧继续只展示自己的内容，不恢复任务与连接面板、技术状态、ID或历史列表；没有自动创建会话。

原冻结包身份保持。真实全App浏览器用例完成显式创建、实际外部报告执行、原SSE和Transcript完成态、SQL唯一Thread/Run及冷重开无重复POST验证。此更正仍在源码和隔离验收环境，尚未更新已安装桌面包。
