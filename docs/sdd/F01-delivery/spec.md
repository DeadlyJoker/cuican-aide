# F01 交付基础规格

状态：实现与集成验证完成，真实模型/完整登录应用验收仍待执行。2026-09-14。基线 `79bf09d88`，分支 `codex/f01-delivery`。

## 范围与用户路径

首版为当前任务提供托管表格交付：上传多份 CSV/XLSX 和一个 XLSX 模板；完整读取所有工作表；显式选择来源与列映射，按模板汇集数据；检查计数、合计与异常；预览/下载真实文件；人工或 Agent 定向修改生成新版本；刷新后恢复。

原始输入和版本由当前任务授权保护。托管输出位置不等于用户任意磁盘路径。录制、Skill 管理、调度、外部发布、Word/PPT 不在范围内。

## 授权与验收边界

浏览器上传、预览和保存复用 Control session/CSRF 与 thread 读写权限。Worker 从真实执行上下文取得来源 Run/任务身份，客户端或模型不能用路径或 runId 自证来源。所有输出是托管内部写入；下载由用户发起。真实模型、GUI 与恢复分别记录，未运行的路径不得标成验收成功。
