## 贯穿四个 feature 的基准任务

用户目标：将两个渠道导出的订单整理到自有模板，排除取消订单，按渠道和币种分别汇总，保留异常记录；下一个周期换数据重复执行。

输入 A：

```csv
order_id,channel,currency,amount,status
A001,直营,CNY,100.00,paid
A002,直营,CNY,50.00,canceled
A003,直营,CNY,80.00,paid
A004,直营,USD,10.00,paid
```

输入 B：

```csv
order_id,channel,currency,amount,status
B001,渠道,CNY,120.00,paid
B002,渠道,CNY,,paid
B003,渠道,CNY,30.00,paid
```

模板包含“明细”“汇总”“异常”工作表，表头、金额格式和一个人工备注区。F01 用真实 XLSX 夹具补充样式、公式和完整内容，避免仅以 CSV 文本模拟 XLSX。

预先确定的业务规则：

1. 原始输入共 7 条。取消订单 1 条，金额缺失 1 条，纳入汇总 5 条。
2. 三个独立汇总：直营/CNY = 180.00；直营/USD = 10.00；渠道/CNY = 150.00。不能把不同币种相加成一个“总金额”。
3. B002 进入异常表，不填 0，不伪造金额；取消记录可追溯且明确排除。
4. 各输出记录能追溯到原文件、工作表及原始记录；模板备注区完整保留。
5. 用户在备注区写“已核对渠道口径”，随后让 AI 更改金额展示精度。新版本保留备注，旧版本仍可读取。
6. 如果 AI 基于旧版本开始修改，而用户已经保存新内容，必须报告冲突或执行已验证的无冲突合并，不得静默覆盖。

第二周期只更换输入和日期参数：A001 改为 A101、金额 110.00；A003 改为 A103、金额 90.00；其他编号同步更换，原币种与状态不变。新的直营/CNY 汇总为 200.00，其余汇总不变。此周期用于检查 Skill 是否错误复用示范中的文件、日期或金额。
