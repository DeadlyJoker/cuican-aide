# F04 Skill 日程接入

状态：S1；基线 `79bf09d88b06fe1d823e5b6107843e13b34f0f4e`。任务 `01a09def-20ad-7c20-bec2-02636e40f050`；owner C04。

## 用户路径与范围

已激活 Skill 的固定版本 → 添加到日程 → 校验参数与交付目标 → 现有日程表单确认时间/时区 → 保存 → 当前 automation-scheduler 触发 → 现有 invocation/Run → 原日程结果对话、运行历史和通知。

本任务不编译或存储 Skill，不建立 scheduler，不修改 runtime/tool 执行引擎，不迁移退休的文件型日程，也不承诺本机睡眠期间执行。C02 由 F03、C03 由 F01 提供；测试夹具不能证明真实上游闭环。

## 需求与验收

| 编号    | 要求             | 验收行为                                                                                                                               |
| ------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| F04-R01 | prompt-only 兼容 | v0 原始记录、摘要、HTTP 请求、instruction 和 receipt 仍能读取/执行；不隐式迁移                                                         |
| F04-R02 | 固定绑定         | 新绑定显式版本化，含 skillId/versionId/contentDigest、参数、依赖和交付目标；拒绝 latest、未知字段、超限；更新 Skill 不影响已保存日程   |
| F04-R03 | 保存准入         | 服务端校验激活/所有权/摘要/参数/依赖/目标；拒绝时不创建日程；客户端不能上传权威 instruction                                            |
| F04-R04 | 执行准入         | 新触发重新校验；缺失、撤权、摘要变化、参数错误、依赖离线、目标不可写、预算不足有稳定失败代码与恢复动作；无上游端口时 fail closed       |
| F04-R05 | 原子与去重       | 使用既有 definition fence、thread fence、receipt 与队列；并发/重复唤醒/重启同一 occurrence 返回同一 Run；失败准入不留下半个 invocation |
| F04-R06 | 历史与取消       | 结果保持 automation origin 与 runId 关联，原历史/通知/Run 取消路径复用；未知外部效果不能自动另建重试 Run                               |
| F04-R07 | 时间与恢复       | 沿用每日/每周/间隔/单次时区语义、最新 occurrence 补执行与分页；无新轮询，离线恢复重新准入                                              |
| F04-R08 | UI 接入          | 从已激活固定版本打开现有日程表单，展示绑定身份，编辑参数/交付目标并保存；未接通能力不得显示假成功                                      |
| F04-R09 | 有界与真实性     | 配置和单段 instruction 有字节上限（instruction <10K tokens）；测试证据分契约夹具、真实存储、真实模型 GUI、跨进程恢复                   |
