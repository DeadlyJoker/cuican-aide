# F02 浏览器示教录制

状态：S1 自检完成；基线 `79bf09d88`；实现及验收待完成。

## 范围与需求

仅支持 CrewON 桌面宿主中一个独立受控教学窗口。普通浏览器工作台提供教学入口；教学窗口有自己的隔离 preload、单个顶层页面和录制存储。网页预览版明确提示需要桌面宿主。沿用 TypeScript、Electron、Node 24 和 pnpm 10。

| 需求 | 可观察行为 | 验证 |
| --- | --- | --- |
| F02-R01 | 用户显式开始；暂停不采集、继续重新接入当前页面、结束封存；同一宿主仅一个教学实例 | recorder 状态与 Electron GUI |
| F02-R02 | 导航、点击、普通输入/选择与筛选动作形成有序稳定 stepId；下载关联触发步骤并保留未知/取消状态 | source、宿主集成、GUI |
| F02-R03 | 密码、凭据、Cookie、后台网络正文不出源；只观察本实例顶层页面。框架、弹窗、文件选择和无法定位动作明确提示 | 源头隐私与失败测试 |
| F02-R04 | 用户回看步骤与脱敏定位图，删去无关步骤、添加说明，revision 冲突不覆盖 | store 与组件行为 |
| F02-R05 | 每次操作原子持久化；重启把未结束录制标为 interrupted，用户显式继续或结束，不伪造成功 | 跨实例/进程恢复 |
| F02-R06 | C01 版本化导出校验结构和 SHA-256 摘要，保留授权来源、证据摘要及删改 revision；F03 有合成样本和契约测试 | contracts 测试 |
| F02-R07 | 200 步、30 分钟墙钟、每事件 8 KiB、每定位图 16 KiB、总计 2 MiB；超限停止采集且已保存记录可回看导出 | budget 行为 |

首发不录制任意桌面应用、全局键盘、跨源 iframe 内部、浏览器扩展、后台网络内容。不生成 Skill，不建执行引擎或调度器，不把导出当作后续权限。定位图以白底形状和目标框表示当前可视区域；不保存页面像素、文字或视频。下载保留事件关联及状态，不读取下载文件正文，不宣称已完成文件交付。

## 用户路径

浏览器菜单“浏览器教学” → 输入教学地址 → “开始录制”授权当前源及本窗口 → 操作页面 → 暂停/继续 → 结束 → 回看、删步、说明 → 导出 JSON。跳往其他源自动暂停，用户显式继续授权新源。重新打开教学窗口可看到本地已保存录制并恢复中断状态。
