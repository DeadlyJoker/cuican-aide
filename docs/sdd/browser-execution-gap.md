# 浏览器执行闭环补充边界

2026-09-14，F03 在 S1/S2 接线检查中确认：公共基线 `79bf09d88` 的 `apps/crewon-ui/electron/browserViews.ts` 仅支持创建、导航展示、布局和销毁，没有供运行时使用的定位、点击、输入或下载执行端口。现有 `CompositeToolRuntime`、`MCPToolRuntime` 与 `DeviceToolRuntime` 可复用，但没有连接到这个 WebContentsView 的浏览器执行器。

这意味着 F02 能录制、F03 能保存 Skill，仍不能证明所教方法可真实执行。为完成既定 E04/E05 路径，增加 F05 独立配套任务。它补齐四个产品 feature 的执行依赖，不另建 Agent 引擎或调度器。

## F05 责任与最小范围

- 调查现有工具注册、设备执行与 Electron 宿主链路，选择一个真实部署可接通的适配路径；先提交 SDD，说明为何复用该路径。
- S1 已选择现有 ToolRuntime/CompositeToolRuntime → 仅本机认证桥 → F02 同一 WebContentsView。首发部署范围为 Electron 与 worker 共机；远程/Team 能力未接通时明确不可用，不伪装成已可调度执行。
- 在一个受支持的 CrewON 浏览器会话中执行导航、有界页面观察、目标定位、点击、普通输入、选择与下载；与 F02 使用兼容的页面/目标语义。
- F05 负责浏览器执行协议、宿主适配器、既有 ToolRuntime 接线与执行行为测试。F02 仍负责录制和教学窗口生命周期；F03 仍负责模型转换、Skill 准入和真实 Run；F01 仍负责文件导入及交付。
- 工具只接受明确动作与数据，不向模型开放任意 JavaScript、任意本机路径或全局应用控制。身份、浏览器会话、工具权限和当前页面状态逐次检查；用户接管、取消、撤权、页面代际变化时不继续旧动作。
- 观察结果保留经过敏感过滤的任务相关导航模板与普通控件当前值/选中项，以核对日期和筛选状态；不一概抹去普通输入值。敏感字段排除，观察保持有界。
- 录制和 Agent 操作同一页面时必须有明确互斥/模式切换，不能把 Agent 自己的动作录成用户示教。
- 下载完成以宿主实际事件及持久字节为准，通过授权文件引用交给 F01；不知道效果是否发生时保留 unknown，不盲目重放点击或下载。
- 不支持的 iframe、弹窗、canvas、验证码和登录交互明确交给用户；不将这些扩展成首发全部浏览器自动化承诺。

## C05：浏览器执行端口，F05 owner

具体 schema 由 F05 设计，跨任务最小语义包括：授权会话引用、页面代际/观察版本、明确动作、可解释目标、请求身份、完成/失败/未知状态，以及有界观察或授权下载引用。F02 与 F05 协商最小宿主接入端口，避免共同改写窗口管理；F03 引用实际已注册工具身份，不猜测工具存在。C05 不复用 C01 的录制来源声明作为执行权限。

协调已确认三个工具：`crewon_browser_observe` 提供有界观察；`crewon_browser_act` 保持逐次审批；新增 `crewon_browser_act_scoped` 只执行独立显式授权覆盖的动作。第三工具的静态 policy 为无需重复审批，宿主仍须在副作用前逐次核验真实 Run、固定 Skill 版本、本次参数、任务/会话和 grant 当前状态。缺失授权或范围不符时拒绝，不自动扩权；转原 act 仍需既有工具权限与审批。

grant 绑定真实版本、任务、会话授权 epoch、精确页面/origin、动作与角色/名称，输入和导航模板绑定经核验的本次参数或用户批准字面值。宿主授权 epoch 与每次导航变化的 page generation 分开：授权范围内导航可继续执行，动作仍校验当前观察；接管、撤权、窗口替换使旧授权失效。F03 提供真实 Run 到 Skill 的解析及重新准入，F04 提供真实 Automation invocation 中冻结的版本/参数；模型不能自报这些身份取得权限。

## 验收与依赖

F05 独立测试使用合成业务页，覆盖导航后旧目标失效、重复请求、取消/断连、权限失效、人工接管与下载关联；真实 Electron 页面动作单独记录。F03/F05 联合验证从真实 Run 发出的工具调用可改变受支持页面并获取文件，F01 验证文件进入真实交付链路。仅有 DOM fixture 或端口 mock 不算 E04 完成。

不能把每次点击都需人工批准的流程标为 E05 自动重复执行。已确认的局部授权方案需覆盖无授权拒绝、撤销竞态、导航后连续执行、不同周期的日期参数、目标/参数越界与同请求重放；实现和真实验收仍在进行。录制、Skill 激活与日程存在均不自行授予浏览器操作权限，不修改全局工具安全策略。

依赖顺序补为 F02 录制 → F03 方法生成/调用 + F05 浏览器执行 → F01 文件交付 → F04 周期触发，各任务继续并行完成无依赖部分。当前仍未完成全链路验收。
