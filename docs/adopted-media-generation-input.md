# 已采用角色图接入生成输入

2026-10-07，接续[素材冻结与准备](./adopted-media-material-preparation.md)。宿主内部已支持将已采用的 T10 角色图与原概念图混合保存为 D18 分镜输入，逐张准备素材，并提交到原 TaskCore / Turn。UI、Agent 和正式桌面组合的采用入口仍待接入，本增量不表示完整短剧链路已上线。

## 输入协议与兼容

调用方继续提交项目内的素材 ID、内容版本和参考版本。新增的统一参考解析服务读取当前素材记录，按实际参考版本选择概念图或媒体结果读取器；调用方不能指定来源类型、图片地址或字节。

全部引用概念图时仍写入 `crewon.project-media-input.v1`，旧字段和摘要计算保持兼容。只要包含媒体结果引用，就写入 `crewon.project-media-input.v2`。每个媒体引用明确记录 `sourceKind: "media-result"`、原候选及生成出处、原 Run / operation / 输出序号和配置摘要，不伪造概念图关联。解析器拒绝版本与来源不符、混入旧字段或出处不一致的记录。

项目、剧本、素材内容、选中参考、安装包和配置仍须通过原事务内校验。Store 在同一连接上复核原保存候选与生成历史。原 SQL 表、幂等键和 Turn 提交路径保持不变。宿主内的写入证明有总大小上限，每个媒体来源另有独立上限；这些证明不会注入模型上下文。

## 素材准备与宿主组合

`createProjectMediaMaterialRuntime` 提供可选的 `adoptedMedia` 组合参数：原结果发布器、结果读取权限和媒体素材冻结权限。原调用方不传此参数时继续使用原概念图路径。实际启用前仍需完成 Control / Worker 的明确组合接线；这里不自动开放采用能力。

准备器按保存的每张参考图选择原概念图准备器或媒体结果准备器。缺少媒体结果依赖时在任何图片上传前拒绝整个输入。媒体结果从原加密档案读取；场景和其他概念图继续走原读取流程。每个返回的冻结记录还须与保存的来源类型及媒体出处一致。D18 的两个角色仍不能使用相同图片字节。

宿主组合只拥有自己的素材档案和生命周期，关闭时不会关闭传入的结果发布器。读取和冻结权限保留独立校验。新版输入记录不兼容旧宿主，因此不能仅升级插件包就向旧桌面端开放这一入口。
