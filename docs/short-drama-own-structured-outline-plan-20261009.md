# 自动计划自身生成结构化大纲并衔接剧本

2026-10-09。源码提交 `1d85e3bf6`，干净桌面验收工作树 `3fb014b25`。本轮接通计划自身的 v2 大纲结果、采用和分集接力；完整复刻目标仍未完成。

## 行为与兼容性

`outline_change` 在原大纲保存事务中核验原计划 Run 标记、Stage、actor、安装来源、工具回执和确切分集 ID，并提交原结果检查点。大纲历史、版本摘要、会话、工作空间、Run 和计划记录保持；没有新增数据库表或重写旧记录。独立大纲 Run 在没有计划标记时仍可正常保存。

原计划的 `whenUnchanged` 仅采用该完成阶段的确切大纲结果；采用使用结构化命令的 v2 回执命名空间、现有质量与当前来源校验，并在同一事务推进原检查点。捕获的计划选择资格只允许选择这个大纲，不能授权结构化内容编辑；旧 UI/Run 编辑资格仍拒绝。后续 script Stage 引用原大纲摘要和分集 ID。自动采用服务是显式可选依赖，旧组合没有这个服务时继续旧行为，v2 采用缺少服务则暂停。

手动采用观察原选用回执并等待明确“继续”，不借此创建或批准 Run。采用后改编方案变化会阻止继续，原选择历史保留。原计划外部形状、并发 1、旧严格 v1 读取协议、冻结短剧 47 与宿主样式未改。质量未达标的候选沿已有 `result_invalid` 暂停原因保留，后续剧本不执行。
