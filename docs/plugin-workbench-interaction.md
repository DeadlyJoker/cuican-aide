# 插件工作台交互边界

插件复用主 Agent 聊天、左侧目录和右侧工作台。插件进入自身工作场景，不修改普通工作会话的页面、历史或设置。

- 左侧只出现一次插件标题，下面管理项目、创建入口、归档状态和制作阶段。新建与切换阶段是页面导航，不自动执行模型或生成工作流。
- 中间仅展示通过真实插件会话或任务端口打开的会话。账号范围改变即撤销；目录暂时不可用也不能显示原工作会话。没有项目会话时给出入口提示，阻止误把消息发进原会话。
- 右侧只承载当前阶段的成果和编辑。项目名称由左侧和标签承担，不重复显示大标题和路径；空的恢复面板不占视野，必要的历史、归档和恢复操作保持可访问。
- 工具与插件共享一个标签组件。叉号关闭单个标签，收起保留标签，加号同时提供插件页与原工具入口；关掉当前插件最后一页时保留其他插件或工具页。
- 页面身份属于当前账号及安装的精确包，不跟随普通会话 ID 变化。进入项目对话和模型提示更新不能重建插件页面。后台目录发现的短暂失败保留挂载；实时租约检查和每次服务调用继续校验授权，明确拒绝立即撤销。
- 插件内不显示普通工作场景和工作模式切换；离开插件后保持原有能力。

包升级必须同时允许旧、新两个已审批的精确摘要，才能读取原选择版本并通过 CAS 安装；同名未知摘要仍拒绝。审批数量、参数形状、当前成员资格、profile 和 epoch 校验不变。发布目录必须由实际服务运行 UID 持有且无组/其他用户权限；跨系统打包不能沿用开发机的 UID。

验收应覆盖原会话进入插件、打开项目会话、切换项目/阶段、关闭一个标签、从加号打开工具与插件、收起再打开，以及等待至少八秒后的页面稳定性。演示行程和完整短剧生成服务的可用性单独验证，不能由页面可打开推断。

多页面使用同一登录 Cookie 时，同一有效 PIM 凭据复用会话；Cookie 已变化导致旧 CSRF 失效时，只有 BFF 的转发前同步标记允许一次凭据同步与重放。普通拒绝不重试，CSRF 校验不被跳过。
