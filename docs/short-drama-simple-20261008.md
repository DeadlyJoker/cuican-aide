# AI 短剧：对话优先与阶段 Skill

日期：2026-10-08。桌面 0.1.41，短剧插件 36.0.0。本轮收敛交互并修复资料读取、阶段发现；完整短剧生产目标尚未完成。

## 交互与插件边界

进入插件仍先到项目首页。进入项目后只突出「开始/继续与 Agent 对话」，流程默认收起。展开「查看流程与产物」可查看需求、大纲、分集剧本、角色、美术、参考素材。正文先于编辑器，候选/已采用与版本直接展示；编辑、版本管理、关联会话、自动计划和恢复记录按需展开。尚未实现的视频页面不再显示为失效入口。

所有 Agent 对话复用主页的 CommandWorkspace 对话与 Composer：插件经现有 `openConversation` 导航到真实绑定的 Thread，由宿主提供模型选择、附件/上下文、权限、工具执行、流式回复和恢复。插件不实现第二套聊天输入、模型请求或会话记录；阶段与 Skill 只补充项目上下文，执行仍受实际授权限制。项目首页的需求表单、产物编辑器和计划参数不是独立聊天框。

布局样式仅在短剧根节点内调整，保留原宿主侧栏、账号设置、窗口按钮和顶部横向避让；最终包宿主 CSS 与 0.1.37 一致。

## 服务修复与兼容

- 之前资产 V2 和已保存结果的读取被错误地绑在「允许上传参考图并生成」上。现在本地资料/恢复/结果读取可以独立准备，结果权限只有 read；生成、上传、发布仍单独授权。不同包不会继承另一包的发布权限。
- Control 在准备只读结果服务时迁移所需本地表，避免新配置缺少 schema；没有创建生成 owner、发送供应商请求或授予网络权限。
- 真实模型按插件说明先调用 asset_context_read，却被文字阶段拒绝。现在只接受已声明资产上下文适配器的空对象、只读探测；文字 Run 返回 scope=null，再读取真实文字阶段。跨项目资产读取、写入、非空参数、其它适配器和媒体阶段隔离保持原约束。既有持久化阶段格式不变。

- 模型生成的非法文字工具参数在实际插件派发前返回有界错误提示，供模型纠正；不再让同一命令进入 Worker 无限重试。授权拒绝、取消、租约撤销及派发后的不确定结果仍保留原语义。未使用的执行预留及时释放；错误回执丢失后可在冷 Worker 重算相同结果。
- 真实 Responses 模型把可选字段自动收紧为必填，导致需求读取始终夹带正文分支参数。传输层针对存在可选字段的 schema 显式发送 `strict: false`，原必填/自定义工具保持原报文，工具 schema、宿主校验及执行权限均不变。此默认行为见 [OpenAI 文档](https://developers.openai.com/api/docs/guides/function-calling#strict-mode)；HTTP 与 WebSocket 共享序列化。
