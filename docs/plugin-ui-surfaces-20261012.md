# 插件三栏扩展边界

用户要求：插件直接进入左侧主导航，安装的清单指定图标；左侧内容栏可提供目录、项目空间或导航标签；中间继续使用原 Agent 对话；右侧可主动开关、新建插件专属页，同时保留原工具标签。

## 本轮已实现

主导航从当前已安装、启用且通过原 UI Catalog 校验的模块生成入口，默认图书图标。图标由宿主绘制，支持 `book-open`、`film`、`image`、`folder`、`layout`、`puzzle`，清单不接受远程图片地址、SVG 或脚本。当前按 contribution 生成入口，多 contribution 聚合为单插件入口仍需完善。

模块可在原清单的 contribution 上声明两个宿主表面：

```json
{
  "id": "workbench",
  "kind": "module",
  "slot": "main.content",
  "title": "AI 短剧",
  "icon": "film",
  "surfaces": ["workbench", "sidebar"]
}
```

缺少 `icon` 的旧清单默认图书图标，缺少 `surfaces` 的旧清单仍只挂载工作台，不会被隐式复制到左侧。新字段保留在实际安装清单及原 Catalog 中；它们是签名/摘要覆盖的包元数据，不是可绕过安装确认的覆盖项。旧宿主会拒绝未知字段，因此新增声明的插件必须使用支持这些字段的宿主；未改变旧清单的输出形状。

左侧插件 UI 只进入宿主的内容栏，保留主导航、账号区域、中间对话与原工作空间管理。宿主使用原 UI loader 和真实 mount lease，分别管理每次挂载的生命周期；未获声明的模块不产生 sidebar 挂载。挂载时的 `props.data.hostPresentation.surface` 为 `sidebar`，插件可据此提供自己的目录或项目列表。旧工作台 props 不新增这个字段；缺省按 workbench 处理。界面提示不授予项目、会话、文件、模型或工具权限。

声明了 sidebar 的插件关闭右侧页面时，左侧选择和自定义内容继续保留；再次点击其主导航入口可重开右侧。旧的 workbench-only 模块保留原关闭行为。

插件切换、卸载、Catalog 撤销与登录生命周期仍由原安装和 UI 宿主收回挂载。共享服务保持原 tenant/space/actor/profile/plugin/publisher/project 隔离。项目空间使用原管理服务与显式项目所有权，不新建普通工作空间管理器，也不把 UI 中的项目 ID 当作执行或文件授权。

插件打开时右侧显示原有工具页的标签，点击可回到原页面，原页面和中央输入框不被替换。新建多个插件页面实例的协议尚未实现；当前这一变动不能宣称满足全部多页要求。

## 下一段必须完成的协议

1. 一个插件一个主导航入口；多个 contribution 和页面实例由插件内容栏、右侧标签管理。
2. 宿主签发页面实例 ID；页面只引用安装清单中已批准的 contribution。单实例上下文有大小限制，单插件页面数有上限。
3. `openPage`、`activatePage`、`closePage`、`toggleWorkbench` 只操作发起插件所属的页面，不允许任意全局路由、关闭其他插件页面或覆盖原工具页。页面路由数据只用于展示，不作为会话绑定或文件权限。
4. 同一插件的 sidebar 与页面通过宿主管理的导航状态联系；不靠跨窗口全局 DOM 或裸事件广播。账号、profile、package/selection 变化立即收回导航请求和实例。
5. 原 Agent composer、模型选择、消息和资源能力只有一套；导航切换不创建另一个聊天框、不清理草稿、不自动执行任务。打开项目对话仍由原服务读取实际绑定后再切换。
6. 将短剧包适配新 sidebar 与页面 API，重新构建不可变包，经原安装流程更新。当前已安装短剧 47 没有声明 sidebar，不能把宿主插槽的单元测试当成它已完成适配的证据。

## 当前证据与限制

相关工作台、Catalog、模块宿主与插件 UI 生命周期测试 249/249，通过，无跳过；清单协议测试 29/29，通过，无跳过；contracts typecheck、UI production build 与 TypeScript boundary 通过。新增交互测试覆盖主导航打开插件、左侧自定义内容切换和收回、保留中央 composer、从插件切回原工具标签。

主导航新增入口有独立快照。既有导航样式快照存在此前账号浮层 CSS 规则未同步的问题，本轮没有为取得通过而更新那份旧快照。完整 UI 回归的已有失败尚未完成清理。本轮不是正式桌面发布，也不是插件多页面和短剧新 sidebar 的最终验收。
