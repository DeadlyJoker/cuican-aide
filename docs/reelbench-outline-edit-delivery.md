# AI 短剧产物编辑交付

本轮范围是小说改编大纲的手动保存和编辑。它仍在 AI 短剧插件内，沿用 CrewON 的主题、项目目录和主页 Agent 对话。完整 ReelBench 复刻目标继续执行，本轮不代表所有阶段已经完成。

## 用户可见行为

- 小说项目确认改编方案后，可以填写大纲梗概，再添加分集、角色、场景和道具。
- 打开产物直接看到正文；编辑表单、制作提醒、质量问题和历史记录按需展开。
- 修改一个分集会保留它的稳定身份、场景及角色引用和未修改字段。
- 每次保存形成新内容版本。满足现有质量检查的版本可采用；历史版本仍可打开。
- 保存结果不确定时，页面保留编辑并允许重试同一原请求。刷新读取不能当成保存成功。

## 实现与验证

原 `crewon.project-outlines` API2 保持只读。新可选 `crewon.project-outline-edits` API1 提供保存候选和采用版本，通过原安装、挂载、身份及项目授权路径，提交到原数据库；不启动模型任务或媒体生成。

SQLite 与 PostgreSQL 的实际 HTTP 集成测试覆盖安装包声明、原文上传、小说创建、方案确认、首次保存、精确重试、修改、过期版本冲突、采用、完整读取及权限撤销。独立插件测试覆盖产物编辑、字段保留、请求重试及不匹配响应。

桌面连续升级时发现旧工作流审批记录保留两种工作流，原配置只容纳 16 条，在第九个版本准备时失败。修复将工作流记录上限与既有 32 个已批准包、每包两种工作流对齐；保留旧版本身份、明确用途、重复检查和发布审批，不删除历史记录或增加执行权限。配置仍有字节上限，磁盘准入限制保持原样。合同回归 6 项和原桌面准备回归 61 项通过。桌面采用宿主与运行时更新，原页面资源保持字节一致。

## 真实桌面验证进展

已安装桌面宿主 0.1.43，原宿主页面的 15 个资源文件逐个摘要一致。原小说验收项目的三集旧格式大纲已保存，但不能据此认定新结构化保存已通过。

实际结构化保存发现插件省略了调用选项，原桌面加载器要求传入选项对象，因此在进入宿主调用端口前拒绝请求。调试栈和只读数据库检查确认该失败请求没有提交记录。修复版 44.0.0 在编辑控制器和公开客户端中明确传入空选项，同时保留显式取消信号。独立插件的 407 项检查通过，包含真实界面操作对调用选项的回归断言；合同类型检查和仓库边界检查通过。

44.0.0 已通过原设置入口安装并选中，沿用原生成地址、预设和基础执行范围，参考图上传与生成授权保持关闭。切换运行环境后，桌面启动阻塞在 macOS 钥匙串读取；本机配置的只读解析通过，保留了 20 条工作流审批记录和 15 个公开包。尚需系统解锁后完成新结构化大纲的实际保存、修改及重新读取验证，不能把模拟界面或 HTTP 集成测试作为这项桌面验收的完成证据。
