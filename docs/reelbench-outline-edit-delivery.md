# AI 短剧产物编辑交付

本轮范围是小说改编大纲的手动保存和编辑。它仍在 AI 短剧插件内，沿用 CrewON 的主题、项目目录和主页 Agent 对话。完整 ReelBench 复刻目标继续执行，本轮不代表所有阶段已经完成。

实际模型更正：界面选择 gpt-5.6-sol 的第三次请求仍由固定的 gpt-5.5 AgentVersion 执行；不能记为 5.6 供应商过载。目录与模型传递待修，见[模型选择核验](desktop-project-model-selection-20261009.md)。用户要求不再使用 5.5 后没有继续发送请求。

## 用户可见行为

- 小说项目确认改编方案后，可以填写大纲梗概，再添加分集、角色、场景和道具。
- 打开产物直接看到正文；编辑表单、制作提醒、质量问题和历史记录按需展开。
- 修改一个分集会保留它的稳定身份、场景及角色引用和未修改字段。
- 每次保存形成新内容版本。满足现有质量检查的版本可采用；历史版本仍可打开。
- 保存结果不确定时，页面保留编辑并允许重试同一原请求。刷新读取不能当成保存成功。

## 实现与验证

原 `crewon.project-outlines` API2 保持只读。新可选 `crewon.project-outline-edits` API1 提供保存候选和采用版本，通过原安装、挂载、身份及项目授权路径，提交到原数据库；不启动模型任务或媒体生成。

SQLite 与 PostgreSQL 的实际 HTTP 集成测试覆盖安装包声明、原文上传、小说创建、方案确认、首次保存、精确重试、修改、过期版本冲突、采用、完整读取及权限撤销。独立插件测试覆盖产物编辑、字段保留、请求重试及不匹配响应。

桌面连续升级时发现旧工作流审批记录保留两种工作流，原配置只容纳 16 条，在第九个版本准备时失败。修复将工作流记录上限与既有 32 个已批准包、每包两种工作流对齐；保留旧版本身份、明确用途、重复检查和发布审批，不删除历史记录或增加执行权限。配置仍有字节上限，磁盘准入限制保持原样。合同回归 6 项和原桌面准备回归 61 项通过。桌面采用宿主与运行时更新，原页面资源保持字节一致。

## 真实桌面验证进展

已安装桌面宿主 0.1.44，原宿主页面的 15 个资源文件和 Native Main 保持字节一致。短剧 44.0.0 已完成原入口的执行准备和启用。小说验收项目已实际保存结构化大纲、修改梗概并添加三集；重新进入项目读回候选 v6 和完整正文。只读数据库核验确认五次新保存均有提交记录，旧格式 v1 的原摘要仍保留。证据为 `output/extensions/checks/short44-desktop-write-proof.json`；这是手动保存验证，未代表 Agent 写入、采用或生成通过。

实际结构化保存发现插件省略了调用选项，原桌面加载器要求传入选项对象，因此在进入宿主调用端口前拒绝请求。调试栈和只读数据库检查确认该失败请求没有提交记录。修复版 44.0.0 在编辑控制器和公开客户端中明确传入空选项，同时保留显式取消信号。独立插件的 407 项检查通过，包含真实界面操作对调用选项的回归断言；合同类型检查和仓库边界检查通过。

44.0.0 已通过原设置入口安装、选中并启用，配置为版本 10，沿用原生成地址、预设和基础执行范围，参考图上传与生成授权保持关闭。

钥匙串等待结束后，实际本机服务仍启动失败。用隔离数据副本、实际桌面运行包和无效诊断凭据捕获到 `extension_json_limit`：批准配置已经超过 64 KiB，三处完整配置比较或摘要仍使用单个扩展载荷的限制。修复改用经过原 256 KiB 配置解析器校验的规范序列化，保持排序和既有摘要字节；单个扩展载荷仍限制为 64 KiB。32 个保留来源的真实 Native 文件、安装所有权、配置漂移及执行组合覆盖通过；本轮相关检查合计 42 项，Control 类型检查及仓库边界检查通过。修复包的隔离本机服务正常启动。

真实桌面 0.1.44 启动后曾在再次执行准备时遭遇 `ENOSPC`，无法写入自身的撤销标记，本机服务停止。清理本任务的过期构建副本后，空间恢复至约 2.2 GiB；保留应用和资料备份，未降低磁盘准入限制。正式 App 已重新启动，读回原账号、会话、工作空间和设置；本次原入口执行准备返回成功，随后完成上面的真实保存、修改及重新读取。

此前无损压缩了本任务的 26 份离线数据库及 31 份 App 归档，逐份验证原内容摘要和权限。随后只清理已被取代的构建副本，应用及资料备份继续保留。没有降低原磁盘准入限制或修改原安装数据库。

小说大纲已在 45.0.0 整理为一个主要编辑入口，已有旧大纲按需展开；空项目不再同时显示旧编辑表单。正式桌面已更新为 0.1.45，插件原设置入口已启用 45.0.0、配置版本 11，原宿主资源保持字节一致。409 项插件检查和 SQLite 安装包集成通过，旧 v1 与候选 v6 均保留。

混合格式只读工具和指引修复已发布。同一原会话关联更新至版本 3，工作空间保留；正式桌面的三次外部模型请求因供应商过载失败，尚未执行工具读取，不能记为 Agent v6 验收通过。证据为 `output/extensions/checks/short45-desktop-proof.json`，详见 [Agent 大纲读取连接](short-drama-agent-outline-read.md)。
