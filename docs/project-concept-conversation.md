# 原项目会话中的概念图生成与查询

2026-10-07。修复已绑定短剧项目的原会话无法提交概念图生成的问题。概念图使用既有生成发布资格，原 Store 却只接受文字阶段资格，导致实际桌面入口返回 `project_stage_admission_required`，请求未进入 ComfyUI。

## 兼容边界

本次不改变 HTTP、插件协议、SDK、数据库结构或 UI。仅在原 Turn/Run 提交事务内识别已捕获的概念图生成、查询及历史查询发布资格，检查它与实际项目会话绑定的一致性。发布来源与执行工作流可以是不同插件，校验使用来源插件身份。

新任务要求项目、租户、空间、用户、profile、原会话、工作空间和绑定标记全部一致；绑定和会话必须处于可用状态，来源插件版本、包摘要及选择修订必须与绑定一致。普通任务没有发布资格仍然拒绝，其他项目、已撤销绑定及未更新关联的插件来源不能创建任务。

已提交请求重试沿用原幂等回执。绑定撤销或来源升级不会单凭这个会话检查阻止读取同项目、同来源插件的既有回执；原回执匹配、发布权限及生成来源检查继续执行，不创建第二个 Run。SQLite 使用原事务，PostgreSQL 使用原事务连接和项目、会话锁。

## 验证范围

行为测试覆盖原会话和工作空间保持、缺失发布资格、跨项目、撤销和来源变化的拒绝、查询及历史查询保留原生成关联、幂等重试不新增任务。Native 集成测试从实际项目会话创建入口到概念图生成入口执行。

真实桌面 ComfyUI 提交、结果预览、素材采纳及重启恢复需要另行验收；以上测试不构成真实生图成功的证明。完整短剧流水线及 Agent 自动阶段执行仍继续实施。
