# 多模型插件激活修复

0.1.51 已恢复原管理员登录。原小说会话通过插件的「更新关联并进入」恢复原线程和工作空间，但大纲只读 Run 被 `desktop_plugin_activation_authority_denied` 拒绝，尚未调用模型或项目工具。

实际 Native V2 发布包含同一短剧插件的 8 个模型目标。Control 激活所有者仍要求一个插件只有一个目标，将合法多模型发布误判为重复插件。新增真实 SQLite、Native 私有文件、原业务激活、安装选择和实际 Node 动作测试，修复前复现同一错误，修复后通过。

仅对已发行并经原校验的 Native 发布选择第一个已准备的业务默认目标；其余目标仍交给独立的逐轮模型权限解析。外部旧协议的重复记录仍拒绝，Native 仍核验相同插件包与配置、唯一目标及私有文件所有权。没有移除权限、改写原项目或重放生成。

相关多模型选择、真实激活、撤权与旧协议 31 项检查通过。实际桌面更新与原项目 Agent 读取待验证。
