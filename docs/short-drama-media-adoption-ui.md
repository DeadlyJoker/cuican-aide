## 页面行为

在“参考与分镜探索”预览已保存的 T10 结果，先查看对应角色，再明确点击“采纳为角色参考图”。页面显示角色和内容版本；归档项目、锁定角色、未保存编辑、其他项目或其他角色的结果不能采纳。D18 结果继续作为分镜探索预览，不误作角色参考图。

采纳沿用原候选、Run、结果序号、角色内容版本和当前资产版本。宿主重新校验冻结输入与来源，客户端显示成功后读取原恢复记录、不可变参考、内容和当前状态，核对后确认原记录。采纳后刷新媒体输入的可选素材，新输入引用新参考版本；旧输入仍保持原版本。参考历史同时展示概念图和已采纳生成图。

断线、重新进入和冷恢复只读原记录，不自动重放或确认。用户核对后可以重试原请求，或取消尚未完成的操作；取消与提交竞争时，以宿主返回的已提交回执为准。确认取消之前继续阻止替代写入。原请求、已提交回执和丢失确认响应分别保留，迟到响应不能跨项目更新界面。
