# 已采用媒体参考的原档案读取

2026-10-07，接续[媒体结果原子采用](./asset-media-reference-adoption.md)。本增量让宿主读取已选中的 v2 角色参考及其原始图片，尚未接入下游素材冻结、插件页面或 Agent 采用入口。

## 读取路径

调用只指定原项目、角色及预期素材、内容和参考版本。Application 先通过原项目与素材服务核验归属、当前指针和上游依赖，再授予所选参考对应的原 Run、输出序号的读取权限。Store 在原项目事务中复核当前记录、已保存候选、原生成输入及历史参考；不接受调用者指定图片 URL、源对象或字节。

`ProjectAdoptedMediaReferenceReader` 通过原结果发布服务读取加密档案，核对候选身份、PNG 尺寸、字节长度和摘要，然后再次检查项目、素材选择、权限和取消状态。供应商修改或移除图片不影响已经保存的原始档案；本地档案损坏或缺失则拒绝读取，不重新请求供应商。

锁定的素材仍可按锁定后的准确版本读取。切换回历史 v1 参考继续使用原概念图读取器。新旧来源保持显式区分，不为媒体结果补造概念图关联字段。

返回的完整来源及字节仅供宿主内部使用；其中包含生成输入和配置元数据，不能直接传给页面或模型。读取快照不授予冻结、准备、执行或采用写入权限。
