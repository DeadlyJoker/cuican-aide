# 短剧大纲与剧本：共享成果协议

日期：2026-10-05。此增量是[完整短剧方案](./short-drama-agent-workflow-design.md)中文本阶段的共享存储与命令底座。实际 Agent 工具和插件编辑页面仍需要后续接线；这里的 HTTP 可用不代表普通对话已经能自动制作短剧。

## 业务模型

大纲和分集剧本分别使用稳定的成果 ID。一个项目只有一个逻辑大纲，同一集只有一个逻辑剧本。每次保存追加不可变的候选修订；选用指针和锁定状态属于成果头，使用独立的修订号比较并更新。文本写入不改变原 `CreativeProject` 的修订号。

大纲包含标题、一句话故事、故事梗概和分集标题/梗概。剧本包含标题、场次、地点、时间、动作和对白。首版最多 16 集、每集 32 场、每场 64 句对白；规范化内容的大纲上限 16KiB，剧本上限 32KiB。局部集/场 ID 是引用标识，不构成访问权限；对白中的人物名也不冒充已建立的角色资产。

候选保存确切需求修订及摘要。从大纲生成的剧本还保存大纲成果 ID、内容修订及摘要，并核验该集确实存在于来源大纲中。用户可以直接导入已有剧本，以 `outline: null` 明确表示没有来源大纲；服务不替用户虚构生产记录。

只有真实的历史依赖才能用于候选。选用时要求需求仍是当前版本；有来源大纲的剧本还要求该大纲修订仍被选用。过期成果的历史和选用指针保留。读视图返回 `unselected`、`current` 或 `stale`，并说明需求变更或大纲选用变更。这个状态是读取时的投影，实际写入和后续执行仍需再次核验。

锁定需要已有选用修订。锁定后仍可以探索新候选，但不能换掉选用版本；解锁是独立的明确命令。较早请求使用过期的成果头修订时产生冲突，不能覆盖用户后来的编辑或选择。

## 共享命令

`ProjectTextApplicationService` 的四个写命令是：

- `saveOutlineCandidate`：保存大纲候选。
- `saveScriptCandidate`：保存某集剧本候选，来源大纲可以明确为空。
- `selectRevision`：以成果头修订号选用确切内容修订。
- `setLocked`：以成果头修订号锁定或解锁。

调用方只提供业务字段、期望成果头修订和幂等键。成果 ID、当前身份、所有者、时间与内容摘要由宿主产生和核验。新成果的期望修订为 0，随后必须使用服务返回的真实成果头修订。

同一调用主体、命令类别和幂等键重放时返回原持久结果；内容不同则拒绝。重放仍检查当前所有权和访问权限。两个入口必须共享同一真实执行意图才能共用幂等键；本底座不会把两个随机键或相同文本自动合并为一次执行。

只读命令提供逻辑大纲/分集剧本、成果详情、确切修订以及有界成果/修订分页。列表不能替代确切依赖读取。

## 存储与兼容

新表为 `project_text_artifacts`、`project_text_revisions`、`project_text_mutation_receipts`，拥有独立的 schema version 1。适配器借用现有 SQLite 父连接或 PostgreSQL 父连接池与生命周期；不建立第二套产品数据库。

写事务重读实际项目所有者、项目是否归档、成果头、需求及来源大纲，比较成果修订，然后一并提交成果头、内容修订和回执。PostgreSQL 使用原项目写入的同一 advisory lock，因此归档、需求修改和文本写入能正确串行；事务中不会再借一次父连接。SQLite 使用实际父连接上的写事务。

旧项目 schema version 1、旧项目回执类别、概念图、Run、插件 SDK v1 与 Short12 包均保持原形状。新的 Control 组合配置明确提供 `textArtifacts: { version: "crewon.project-text.v1" }` 才迁移并注册文本服务；旧配置不隐式创建文本表。

文本服务复用实际 `CreativeProjectAuthorizationPort` 和项目所有权检查。当前只能接受基础提交撤权检查，明确拒绝旧 UI 六类动作的插件事务资格；Agent 工具不能把旧 UI invocation 或 Run 准入伪装成文本写入许可。

## 下一步接入

真实 Agent 接线要增加具名宿主项目服务及真实 Run/工具调用资格，由宿主解析 principal、绑定确切包和工具派发、生成稳定命令键。插件安装和 Node 信任不能替代项目访问权限。普通聊天当前没有插件任务 admission，不能通过提示词或伪造准入补齐。

插件工作台随后使用同一服务编辑、比较、选用和锁定。新增页面仍局限在短剧插件内容区，保持原宿主页面与侧栏样式。验收目标继续是“想法 → 三集大纲 → 一集剧本 → 手动改台词 → Agent 继续修订”，需要真实工具路径、流式结果和重连验证之后才算完成。
