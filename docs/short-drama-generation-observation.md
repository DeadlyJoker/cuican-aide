# 短剧 11.0.0：自动跟进已保存的生成记录

生成或查询的受理回执返回时，Worker 通常尚未完成。原页面只立即读取一次，后续图片需要手动刷新。11.0.0 在选中的保存输入可见时自动跟进原任务记录，图片更新后直接展示；没有修改宿主账号、设置、侧栏、全局样式或 SDK 协议。

## 读取范围与停止条件

观察器只调用原 `getConceptGeneration` 服务，定位仍为冻结的 `{projectId, assetId, assetRevision}`。调用身份、原 Run 与结果投影继续由宿主核验；插件不增加 owner、付款人、供应商地址或新任务参数。只读 UI action 仍使用原 invoke 传输，不能将其底层 HTTP 方法宣称为 GET；宿主自己的记录读取 HTTP 保持原 GET。

每次读取完成后等待两秒，最多六十次自动读取、墙钟两分钟。单次读取十秒超时，撤回当前请求并停止自动跟进；错误明确显示无法读取，手动刷新可开启新的有限窗口。后台读取保留最后确认的图片和原 DOM，避免每次更新闪空；失败清空旧显示，不能将旧结果冒充当前读取成功。

只有原生成 Run 为 completed、failed 或 canceled，全部可见 operation 为 succeeded 或 failed，且没有截断时，普通观察窗口才提前停止。Run 完成但 operation 仍排队、运行或结果未知时，继续有限读取。等待审批或暂停不触发自动恢复；记录读取也不更新供应商状态。

查询受理指向另一个 Run，当前生成投影不包含该查询 Run 的状态。每个新的查询回执开启一次完整有限窗口；不会因原生成的终态提前声称查询已完成。重复回执、相同挂载属性和主题变化不重置期限。冷挂载先收到 accepted 提示、后恢复输入时，也保留这次观察意图。

## 生命周期与兼容性

文档隐藏时撤回读取并暂停下一次自动读取，原墙钟期限继续推进；重新可见只使用剩余预算。编辑、切换保存输入、返回列表、撤权与卸载清除旧观察窗口，晚到结果不得覆盖当前输入。没有生成关联且没有查询观察意图时，只读取一次空记录，不轮询空项目。

公开 SDK 的 abort 可提前结束界面等待。插件读取适配器额外等待本次原 `services.invoke` promise 真正结束，并串行派发本挂载的记录读取；排队请求被撤回后不能再派发。此保证限于原 invoke 边界，不宣称已取消服务端 SQL 或供应商作业。生成、查询、选用和写入的原恢复机制保持。

11.0.0 仍是独立 UI 包，依赖与声明沿用 10.0.0，只改变页面业务行为。旧发行包、旧 SDK tarball 和生产批准/项目映射不更新；安装新包仍需实际包摘要批准及原服务授权，不能沿用旧版本摘要。构建必须在仓外使用公开 SDK tarball 和包依赖，不引入宿主源码。

## 验证边界

独立源码观察器、真实 SDK 取消边界与当前 UI 测试覆盖自然结果更新、冷恢复、有限预算、原回执一致性、隐藏/退出/卸载及迟到结果；自动生成、查询与选用新增为零。既有发行 ESM 套件、原 CommandWorkspace 和短剧样式/快照另行回归。

这些验证使用具名记录和已有样例 PNG，不调用用户 ComfyUI、不充值或扣费，也不能代替 Native 公网生成、当前完整 App 在线 S0 或真实个人积分验收。原 E5 仍需用户选定的实际企业 API。
