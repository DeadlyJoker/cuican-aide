# 插件磁盘不足恢复

日期：2026-10-08。

## 原因与处理

出行助手挂载请求 `POST /api/v1/plugins/ui/mounts` 返回 503 / `storage_capacity_low`。实际磁盘可用空间约 259 MiB，低于宿主 1 GiB 的新操作准入阈值；进入保护后需要恢复到 2 GiB 才重新准入。此前打包留下的重复产物增加了空间压力。

清理本任务生成的重复 `release`、诊断候选及中间应用包，保留源码、冻结 SDK、发行插件、用户数据和回退应用。最终更新完成后可用空间约 3.2 GiB。未降低存储保护阈值、修改插件权限或重放生成请求。

原错误页将所有失败压成「模块暂时不可用」。新版按已知错误码展示磁盘不足或空间检查失败的原因，提供「重新加载插件」按钮；点击只重新获取挂载权限，不执行插件动作。未知错误不暴露服务端细节。

截图中的团队浅灰背景为悬停态；选择出行助手时团队的 `active` 和 `aria-current` 都不再存在，增加回归断言，没有修改原导航主题。
