# 短剧 Agent 创建与 Web 加载修复（2026-10-15）

本轮先在源码与隔离验收库完成修改，不更新桌面，也不提前替换线上候选服务。本文的本地验证不能代替真实 Web 的模型、保存和刷新验收。

## 使用流程

进入短剧插件后，在原主聊天框输入想法并发送。宿主通过原 Foundation 创建接口保存创意与初始参数，先读取项目的实际工作空间目标，再通过原会话接口创建隔离会话，最后提交第一轮 discussion。初始集数留待讨论明确，不把未确认的想法固定为单集。此处是宿主协调用户的明确发送操作，不是宣称模型已经调用了创建工具。

中间复用原消息渲染、输入框及模型选择。原普通会话不作为插件新项目的发送目标。右侧入口不再出现第二个创意输入框或重复创建表单，小说原文导入仍走现有入口；项目成果与后续阶段沿用现有页面和阶段准入。切换阶段仅同步当前上下文，不自动执行。

每个创建步骤先保存原请求键，再派发原写入。丢失响应后仍重试同一请求和版本；未知结果不更换键。刷新后只读恢复待续提示，等待用户显式重试，不自动创建或执行。打开项目后的关闭租约失败不把已提交的 Run 当作未提交重新发送。

## 加载链路

同一真实 PIM 账号在两个标签页持有不同刷新令牌时，复用原有 Cookie/CSRF 身份；新令牌仍需当前 PIM 及 profile 验证，不延长原 Web 会话期限。不同账号、失效令牌、过期 Cookie 和撤销 profile 仍拒绝。

经过摘要校验的入口缓存读取使用原账号会话传输，具备相同的会话续期能力。目录已加载后，网络断开、超时或 5xx HTML 不再被误认为卸载或撤权；明确 401/403 仍撤下可调用内容。缓存不提供离线执行权限，也不证明公网 TLS 问题已经解决。

## 后端接线与兼容性

- Control 私有配置新增可选 `unmeteredAuthority`，使用现有 unmetered 准入类型，提交前复核相同政策版本。显式配置该能力后不需要伪造报价 URL、余额或信用记录；原 metered 配置保持有效，缺少两种资金授权都拒绝启动。
- 可选 `models` 固定声明 scope、完整包身份、配置摘要、模型与目标；读取原不可变 AgentVersion/Deployment 核对，未发布模型和伪造目标拒绝。默认 Agent 不被替换。
- Worker 可选 `projectServiceAuthority` 显式启用原 PostgreSQL 项目、Foundation、大纲和资产服务。服务逐次检查真实任务准入；声明、Skill 或页面选择不构成写权限。源文件准备不会因 Node 服务启用而隐式开放。
- 原 BFF 私有 PIM 桥新增 execution actor/package、项目服务与 unmetered 政策端点。需显式配置 `CREWON_WEB_PIM_PLUGIN_EXECUTION_GRANTS_JSON`：每项包含完整 `scope`、`identity`、允许的 `services` 以及 `unmetered`（可为 null）。未配置端点拒绝执行；UI 的包许可不自动成为执行许可。
- 包元数据 `read` 是独立部署授权，允许原发布 CLI 在没有浏览器会话时读取确切批准包；submit/observe、用户权限、profile 和任务政策仍单独复核。私有端点沿用独立服务凭据与回环网络，不向浏览器提供凭据或新的授权头。

## Web 实测发现的缓存兼容问题

50.2.0 在真实 Web 中完成了主聊天即时显示、实际项目/独立工作空间创建及原 Run 接入。源站验收发现首次入口正常，而已有代码缓存后的条件请求返回 304 会导致导入失败；同一页面改用完整 200 资源读取可正常进入。缓存 v2 使用原账号、精确租约及实际摘要复核后的空 200 和 `x-crewon-plugin-ui-entry: unchanged.v2`，避免把应用自己的代码缓存交给浏览器解释 HTTP 304。客户端必须同时具备匹配账号缓存、精确 ETag 和空体声明才可复用字节，缺少任一项拒绝导入。v1 的 304 保持兼容；旧 BFF 对 v2 不启用优化时仍返回原完整资源。

公网静态资源仍出现连接超时和正文停传；源站同一资源为 200、0.086 秒。模型 gpt-5.6-sol 首次采样已收到协议终态（约40秒），后续采样在响应头前发生 ETIMEDOUT；gpt-6.1-sol 对照 Run 也失败。没有以这两个失败 Run 宣称阶段产出已完成，也没有自动重复创建项目或批量重试。

## 最终缓存与隔离回归

源站真实 Web 已观察到两处视图均 `entry-revalidated → published`，完整挂载约3.9–4.1秒，响应正文为0字节而不是重复下载934KB入口。进入角色页可读到真实空资产列表，并把主 Agent 当前阶段同步为角色；切换不会自动创建 Run。两次显式测试 Run 仍为两个，刷新没有重复创建项目或提交模型请求。

切回普通工作时进一步发现中心聊天仍保留插件历史。现在通过独立的展示范围判定，在插件外遮蔽属于项目的会话与阶段栏；回到工作清除当前选择，项目原会话继续由插件维护。目录撤销时仍按真实项目上下文遮蔽，避免只依靠导航目录过滤。模型调用、权限、账号与项目数据均不因这个展示修复改变。

同一 Worker 的 `/v1/models` 无生成费用对照请求在约748ms发生 AggregateError：两个 IPv4 地址 ETIMEDOUT、两个 IPv6 地址 ENETUNREACH；独立 IPv4 HTTPS 请求约18.5秒后 ECONNRESET。这证明连接故障在模型采样请求体处理之前，不能用伪造产物或反复重试宣称真实生成验收通过。公网接入故障按用户要求暂不修改。
