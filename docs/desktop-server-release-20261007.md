## 桌面故障与处理

“无法连接”已在原 0.1.15 安装版通过系统入口及精简 PATH 环境复现。Finder 不继承开发终端的 PATH；工作空间 MCP 在启动时要求 pnpm 为绝对路径，找不到时抛出 `local_pnpm_path_invalid`。这会中断插件目录准备并阻止 Control / Worker 启动。不是会话数据丢失，也不是需要启动网页开发服务器。

将开发命令路径校验移至实际命令调用，保留原绝对路径约束。缺少 pnpm 或 git 时，目录发现、文件读取及普通对话启动仍可用；调用对应开发命令返回明确错误，不降级执行未校验的程序。

Mac 自定义窗口按钮开启首次点击响应。重新激活和第二实例请求只恢复原来绑定 IPC 的窗口；退出清理期间不再创建未绑定 IPC 的新窗口。后者是代码审查确认的缺陷，未将其冒充本次连接错误的实测根因。窗口最小化、恢复、关闭增加无敏感内容的原生事件日志。

用户再次反馈后，通过物理鼠标坐标点击在 0.1.31 复现按钮无响应。此前使用无障碍操作触发按钮，绕过了鼠标命中检测，因此不能作为鼠标可用性证明。侧栏顶部原生拖拽区域与全局窗口按钮重叠；0.1.32 将全局按钮排在页面内容之后，并为按钮及其扩大命中伪元素显式设置 `no-drag`，让按钮排除区域生效。扩大排除区域不移动可见圆点。

桌面会话初始化失败后最多进行五次退避重试；回到前台或恢复网络时可以再次发现会话。成功后停止轮询，过期请求不能覆盖新会话。此逻辑不重启后台，也不重放业务任务；Web 连接行为保持不变。

定向 Control 回归 24 项、类型检查通过；包含真实 SQLite 组合后的历史查询配置、缺失声明、版本及目标漂移拒绝。正式安装版完整冷启动、执行准备后的后台恢复、新版工作台读取原「夜航 · 插件流程验收」项目通过。正式版物理坐标点击黄、绿、红按钮分别完成最小化、缩放与恢复、关闭，日志记录 `minimize`、`restore`、`closed`，正常退出码 0。
