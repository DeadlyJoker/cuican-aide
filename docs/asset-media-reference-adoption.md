# 已保存媒体结果采用为角色参考

2026-10-07，接续[采用前校验](./asset-media-reference-qualification.md)。本增量实现原 Store 的原子采用与持久回执，尚未向 HTTP、插件页面或 Agent 注册采用入口。

## 数据与事务

采用请求只指定原项目、角色、预期素材版本、已选内容版本、原 Run、输出序号、候选身份及幂等键。Store 在同一个原项目事务内核验已保存候选、原生成输入与历史参考，确认其确为该角色当前内容生成的 T10 结果。

成功时一起写入不可变参考版本、比较并更新原角色的参考指针及版本、保存不可变采用回执。任一步骤失去写入资格会整体回滚。不再次生成、下载或上传图片，不接受调用者提供的 URL、图片字节或源对象。只读查看和采用前校验的凭证不能代替采用写入凭证。

PostgreSQL 的完整前置校验在借用提交连接之前完成，允许通过原单连接池读取项目；事务内仅运行专用的外部授权及生命周期校验。SQLite 在原同步事务内逐步检查有效性。身份和安装状态仍在原提交连接上核验。

同一幂等键、同一请求恢复原回执；同键不同请求拒绝。恢复返回当时保存的素材与参考版本，不把它重新选中。后续改选、锁定或项目归档不改写原回执；调用仍须拥有当前读取及恢复所需的宿主资格。接线时需区分恢复与新采用的授权条件。

## 兼容范围

- 原概念图来源继续使用 `crewon.project-asset-reference.v1`；媒体候选来源显式使用 `v2`，不伪装为概念图选择。
- 原素材表及其 schema 标记不变。历史列 `result_link_digest` 继续作为来源摘要索引：v1 对应概念结果关联摘要，v2 对应媒体候选摘要，读取时按记录版本核验。
- 只新增采用回执表及自己的迁移标记。每个 Store 实例必须显式启用迁移；常规结果保存迁移不会自动启用采用。本次未对用户数据库运行迁移。
- 原 v1 插件公开投影与概念图素材读取器明确拒绝 v2。必须完成新版公开投影及媒体来源读取器后，才能开放页面或 Agent 采用入口，避免使现有页面读到无法展示的参考。
- 主题、UI、SDK、已冻结插件包和用户当前 App 均未改动。后续入口仍放在短剧插件的内容区，遵守[主题及插件范围](./plugin-variability-boundary.md)。
