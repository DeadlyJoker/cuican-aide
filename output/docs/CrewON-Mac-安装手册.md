# CrewON Mac 版 下载安装手册

适用版本：0.1.0（2026-08-05 发布）

---

## 先确认你的电脑能装

| 项目       | 要求                        |
| -------- | ------------------------- |
| 芯片       | Apple 芯片（M1/M2/M3/M4）     |
| 系统       | macOS 10.15 或更新           |
| 磁盘空间     | 至少 1 GB                   |

**怎么看自己是什么芯片：** 点左上角苹果图标 →「关于本机」，看「芯片」那一行。写着 Apple M 开头的就可以装。

> **Intel 芯片的 Mac 目前装不了。** 这一版只出了 Apple 芯片的包，Intel 机器下载下来也打不开。需要的话跟我们说，我们再出一个。

---

## 第一步：下载

打开这个页面，下载 `Crewon_0.1.0_aarch64.dmg`（约 90 MB）：

https://github.com/DeadlyJoker/cuican-aide/releases/latest

页面下方 Assets 里那个 `.dmg` 文件就是安装包。另外两个文件（`.app.tar.gz` 和 `latest.json`）是给自动更新用的，不用管。

---

## 第二步：安装

1. 双击下载好的 `.dmg` 文件
2. 弹出的窗口里，把 **Crewon** 图标拖到 **Applications**（应用程序）文件夹上
3. 拖完就可以关掉窗口，右键点桌面上的 Crewon 磁盘图标选「推出」

---

## 第三步：绕过"文件已损坏"提示（必做）

第一次打开时，macOS 大概率会弹一句 **"Crewon 已损坏，无法打开。你应该将它移到废纸篓。"**

**文件没坏。** 这是因为这一版还没有做苹果的开发者签名，macOS 对没签名的应用一律这么提示。

处理办法：打开「终端」（按 `⌘ + 空格`，输入 Terminal 回车），把下面这行粘贴进去，按回车：

```
xattr -dr com.apple.quarantine /Applications/Crewon.app
```

可能会让你输入开机密码——输入时屏幕上不显示任何字符，这是正常的，打完直接回车。

执行完再打开 Crewon 就正常了。**这一步只需要做一次。**

> 如果提示的是"无法打开，因为无法验证开发者"，那就换个做法：在「应用程序」里 **右键**点 Crewon → 选「打开」→ 再点一次「打开」。

---

## 第四步：首次启动

打开 Crewon 后，会先看到「正在连接企业账号与资源目录…」，然后是登录界面。

启动时它会在后台自己拉起一个本地服务，第一次可能要等十几秒，属正常。

### 登录

三种方式，用哪个取决于你们的账号是怎么开的：

- **用户名 / 企业邮箱 + 密码** —— 管理员给你开好账号后直接登录
- **企业微信扫码** —— 需要管理员在后台配好企业微信对接，配好了登录页会出现扫码按钮
- **自己注册** —— 在登录页切到「注册」，提交后等邮箱验证或管理员审批

---

## 需要提前准备的：账号服务

这一点要说清楚，免得你装完发现登不进去。

**Mac 客户端默认连的是本机 `127.0.0.1:8000` 上的账号服务。** 也就是说，光装这个 App 还不够，得有一个能连上的账号服务端，否则登录页会报"账号服务不可用"。

两种情况：

- **公司已经部署好了服务** —— 找管理员要服务地址，我们会给你一个配好地址的安装包，或者告诉你怎么改配置。
- **你是自己试用** —— 需要我们协助把服务端跑起来，直接联系我们。

装完卡在登录页的话，基本就是这个原因，不是 App 装错了。

---

## 以后怎么更新

App 内置了自动更新，有新版本时会自己提示，点确认就行，不用再走一遍上面的流程。

---

## 遇到问题怎么排查

| 现象                    | 原因和处理                                                    |
| --------------------- | -------------------------------------------------------- |
| "Crewon 已损坏"          | 没签名导致的误报，执行第三步的 `xattr` 命令                               |
| "无法验证开发者"             | 右键点图标选「打开」，再确认一次                                         |
| 双击没反应 / 闪一下就关         | 大概率是 Intel 机器装了 Apple 芯片的包，确认一下芯片型号                      |
| 一直停在"正在连接…"           | 本地服务还在启动，等 20 秒左右；一直不动就退出 App 重开                         |
| 登录页提示"账号服务不可用"        | 账号服务没起来或地址不对，见上面「需要提前准备的：账号服务」                           |
| 登录不上，提示密码错误           | 找管理员确认账号状态；企业微信开的账号可能还没设过密码，改用扫码登录                       |

上面都试过还不行，把出问题的截图发给我们，附上系统版本和芯片型号（「关于本机」里那两行），我们直接看。

---

## 卸载

把「应用程序」里的 Crewon 拖到废纸篓即可。

如果想连配置和缓存一起清掉，在终端执行：

```
rm -rf ~/.crewon
```

> 这一条会删掉本地的配置和任务记录，删了不能恢复。只在确定不再用、或者要彻底重装时才执行。
