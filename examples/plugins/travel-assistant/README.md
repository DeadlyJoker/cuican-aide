# 出行助手 · 独立插件演示

本包是 `crewon.travel-demo@0.2.3` 的 UI-only 插件，贡献 `main.content`。左侧为行程与功能目录，中间复用宿主原 Agent 对话框，右侧为独立页面；插件不提供第二套聊天框。它模拟上海到北京的成人单程出行：确认预算/人数/到达时间、比较高铁与机票、手动触发降价、确认下单、响应丢失核查、付款与出票。所有班次和票价均为固定虚构样例，不代表实际查询结果。

不连接12306/航旅纵横，不调用宿主任务或供应商，不扣票款或CrewON积分，不创建后台监测。状态只在本次挂载内保留，关闭或卸载重置。已提交的模拟订单保留原需求快照，修改计划或暂停监测不会修改它。演示最多一笔订单，重复提交不产生第二笔。

## 独立构建

使用Node.js24、pnpm10。目录已附带从公开SDK构建的 `sdk/crewon-plugin-sdk-0.1.3.tgz`，可直接复制整个目录到仓外，执行 `pnpm install`、`pnpm test`、`pnpm preview`。SDK未发布到registry，包依赖使用本地相对路径。

需要更新SDK快照时，先在CrewON插件开发工作树构建并打包公开SDK：

```sh
pnpm --filter @crewon/plugin-sdk pack --pack-destination /absolute/sdk-output
```

复制整个演示目录到仓库外，安装SDK后构建：

```sh
pnpm add /absolute/sdk-output/crewon-plugin-sdk-0.1.3.tgz
pnpm install
pnpm build
pnpm test
pnpm preview
```

打开 `http://127.0.0.1:4318`。预览容器加载与安装包相同的UI产物，不假装是正式CrewON宿主。切换明暗主题不会清空草稿。

## 安装产物

`dist/0.2.3/` 是预构建安装目录，含真实文件SHA-256清单与SDK许可证，交给宿主现有目录安装端口。没有业务执行清单、Node服务或凭据；仅声明可选的 `crewon.plugin-navigation@1` 展示服务，安装器不运行构建脚本。已通过实际CrewON原设置安装流程启用，主界面左侧“出行助手”可直接使用。

`dist/demo.mjs` 是测试专用纯状态模块，不进入安装目录。包独立依赖公开SDK，不导入宿主私有源码。

## 演示脚本

1. 从“出行助理”开始，输入出行需求或点示例提问。核对助理整理的字段，再确认需求：总预算800元，1人，21:00前到。两种交通符合条件，晚间高铁被过滤。
2. 在对话输入“两人同行，预算1600元”，核对后确认；或从“方案与需求”修改人数并确认，看到总价超预算；改预算到1600再确认。
3. 在对话说“帮我盯票提醒”或点击开启演示监测，点击“模拟一次价格变化”，再查看方案。
4. 选择方案，在局部确认面板勾选“模拟提交响应丢失”，确认模拟下单。
5. 核查原订单，模拟提交次数仍为1；依次模拟付款和出票。
6. 点“重新演示”，确认清空本地状态可体验其他场景。切换主题、缩窄窗口、暂停监测，检查需求/订单保留与布局。

验收覆盖纯规则、重复派发与未知恢复、DOM用户流程、主题保留、宿主DOM不变、卸载清理和安装产物字节校验。正式接口、持久调度与支付仍按设计文档另行开发。

## 12306 接入尝试（2026-10-07）

已验证官方查询页面 `https://kyfw.12306.cn/otn/leftTicket/init` 可访问，Agent确认需求后的方案区和“服务连接”均提供官网入口及候补说明。当前为官网跳转，不是API连接；不读取实时余票、登录会话或官网订单，不把模拟记录同步成真实订单。若预览容器拦截新窗口，可在浏览器直接打开上述地址。

本次未找到官方第三方公开售票OpenAPI文档或可申请的开发者密钥入口，不能将网页内部请求当作正式接入协议。后续实时查询、候补和交易须取得可验证的官方/合作方接口文档与授权，并通过CrewON宿主的网络及业务动作端口装配。当前测试12/12通过，包含官方域名、外链隔离、Agent入口与模拟订单不受影响。
